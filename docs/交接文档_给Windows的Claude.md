## 一、先做三件事（1 分钟）

1. **装语雀 skill**（队伍私有知识库要用）：
   ```bash
   git clone https://github.com/flc1125/skills C:\tools\skills
   # 使用其中的 skills/yuque 目录下的脚本：
   #   node read-doc.mjs --id <文档id> --token <token> --execute
   #   node read-repo.mjs --group-login amanannn --book-slug yyfbpg --execute
   ```
2. **配置语雀 token**：向队伍成员索取 token，复制 `skills/yuque/.env.example` 为 `.env` 填入 `YUQUE_TOKEN`（**token 不写进任何仓库文件**）。
3. **恢复 memory**：把本仓库 `docs/memory/` 目录复制到 `%USERPROFILE%\.claude\projects\<你的项目slug>\memory\`（slug 由你的项目路径生成，先打开一次项目让 Claude Code 生成目录）。
