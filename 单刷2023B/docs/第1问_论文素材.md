# 2023B 第一问：多波束测深覆盖宽度 论文素材

## 1. 问题与分析

船沿测线（等深线方向）航行，多波束换能器开角 120°（半开角 60°，与铅垂方向夹角）。海底为单面坡（坡度 α=1.5°），测线垂直于坡面走向。已知测线中心处深度 D₀=70m，相邻测线间距 d=200m。

核心几何：**覆盖宽度是波束边缘与海底坡面的交点间距（水平投影）**，不是简单圆弧投影——左右波束相对坡面的入射条件不同，需要按坡面方程解交点。

## 2. 模型（截面几何法）

坐标系：x 沿坡面走向（测线方向），y 垂直测线（横向），z 向下为正；船在 (0,0)，船正下方海底深度 D。

海底坡面：z = D + y·tanα（向坡下 y 增深）
波束边缘：左波束 z = −y/tan60°，右波束 z = +y/tan60°

解交点得覆盖宽度（水平投影）：

$$W = D\left[\frac{1}{\tan 30^\circ + \tan\alpha} + \frac{1}{\tan 30^\circ - \tan\alpha}\right]$$

其中 D 为测线处水深。沿测线各点水深 D(x) = D₀ − x·tanα（x 正方向为坡上，浅侧）。

重叠率（相邻条带）：

$$\eta_i = 1 - \frac{d}{W_{\min}}$$

W_min 取相邻两条测线中较浅（较窄）者的覆盖宽度。

## 3. 结果

9 条测线（x = −800, −600, …, 800 m）：

| x (m) | 水深 (m) | W (m) | 与前一条重叠率 |
|---|---|---|---|
| -800 | 90.95 | 315.71 | — |
| -600 | 85.71 | 297.53 | 32.78% |
| -400 | 80.47 | 279.35 | 28.40% |
| -200 | 75.24 | 261.17 | 23.42% |
| 0 | 70.00 | 242.99 | 17.69% |
| 200 | 64.76 | 224.81 | 11.03% |
| 400 | 59.53 | 206.63 | 3.21% |
| 600 | 54.29 | 188.45 | 空隙 11.55m |
| 800 | 49.05 | 170.27 | 空隙 29.73m |

结论：**重叠率按相邻条带中较窄者（浅水侧）计算并随测线向浅水区推进递减**，600m 处开始出现覆盖空隙——浅水区条带窄，固定间距不满足全覆盖。

## 5. 论文写作要点

- 模型假设：海底平面坡、波束边缘直线、忽略折射/姿态误差
- 公式推导要写清"波束边缘与坡面求交"而非圆弧投影（常见错误点）
- 结论句：*"在固定测线间距下，覆盖宽度与重叠率随水深线性变化，浅水区成为覆盖瓶颈；重叠率按相邻条带中较窄者计算。"*
