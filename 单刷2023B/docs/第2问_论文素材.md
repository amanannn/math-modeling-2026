# 2023B 第二问：多波束测深的覆盖宽度 W(L,β) 论文素材

## 1. 问题与分析

多波束测深过程中，覆盖宽度不仅随水深变化，还取决于**测线方向与坡面走向的关系**。引入两个量：
- L：测线距海域中心点的距离（海里），L 正方向为坡上（浅侧）
- β：测线与坡面法向水平投影的夹角（测线方向角）

已知：中心水深 H₀=120m，坡度 α=1.5°，半开角 60°，1 海里 = 1852m。

## 2. 模型

**沿测线方向的水深变化**（测线方向与坡向的几何投影）：

$$H(L,\beta) = H_0 - L\cdot\tan\alpha\cdot\cos\beta$$

**视坡角**（地形在测线法线方向的投影坡度）：

$$\tan\alpha' = \tan\alpha\cdot|\sin\beta|$$

β=90°（测线沿等深线）时视坡角最大（=α）；β=0°（沿坡向）时视坡角为 0。

**覆盖宽度**（与第一问同构，用视坡角替换真实坡角）：

$$W(L,\beta) = H(L,\beta)\left[\frac{1}{\tan30^\circ + \tan\alpha'} + \frac{1}{\tan30^\circ - \tan\alpha'}\right]$$

**关键观察**（为第三问铺垫）：β=90°/270°（沿等深线方向）时 W **不随 L 变化**——测线沿等深线走，水深沿线恒定，条带宽度恒定，覆盖效率最高、间距控制最简单。
