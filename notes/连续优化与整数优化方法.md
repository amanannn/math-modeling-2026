## 二、连续优化方法

### 2.1 线性规划 (Linear Programming, LP)

**适用场景**：目标函数和约束条件都是线性的

**标准形式**：
```
min  c^T x
s.t. Ax ≤ b
     x ≥ 0
```

**经典案例 — 生产计划问题**：

> 某工厂生产 A、B 两种产品。A 利润 40 元/件，B 利润 60 元/件。A 需 1h 机器加工 + 2h 人工，B 需 2h 机器加工 + 1h 人工。每天可用机器 8h、人工 10h。问如何安排产量使利润最大？

建模：
```
max  40x1 + 60x2          (利润)
s.t.  x1 + 2x2 ≤ 8       (机器)
     2x1 +  x2 ≤ 10      (人工)
     x1, x2 ≥ 0
```

Python 求解（scipy）：

```python
"""
用途: 线性规划求解 — 生产计划问题
输入: 利润系数、约束矩阵、资源上限
输出: 最优解和最优值
调用: python lp_production.py
"""
from scipy.optimize import linprog
import numpy as np

# min c^T x  → 注意 scipy 做最小化, 需取负
c = [-40, -60]              # 利润取负 → 最大化变最小化

# 约束 A x <= b
A = [[1, 2], [2, 1]]
b = [8, 10]

# 边界 x >= 0
bounds = [(0, None), (0, None)]

res = linprog(c, A_ub=A, b_ub=b, bounds=bounds, method='highs')

print(f"最优解: A={res.x[0]:.2f}, B={res.x[1]:.2f}")
print(f"最大利润: {-res.fun:.2f}")
# 输出: A=4.00, B=2.00, 最大利润=280.00
```

**国赛常考变体**：运输问题、指派问题、资源分配、下料问题、投资组合

### 2.2 非线性规划 (Nonlinear Programming, NLP)

**适用场景**：目标函数或约束中有非线性项

**经典案例 — 选址问题**：

> 在平面上建一座仓库，服务 4 个客户点：(0,0)、(4,0)、(0,3)、(4,3)。求仓库位置使得到各客户的距离平方和最小。

建模：
```
min Σ[(x - xi)² + (y - yi)²]
→ 最优解为各点坐标均值 (2, 1.5)
```

Python 求解：

```python
"""
用途: 非线性规划 — 无约束选址问题
输入: 客户坐标列表
输出: 最优仓库位置和总距离
"""
from scipy.optimize import minimize
import numpy as np

customers = [(0,0), (4,0), (0,3), (4,3)]

def objective(pos):
    x, y = pos
    return sum((x - cx)**2 + (y - cy)**2 for cx, cy in customers)

res = minimize(objective, x0=[0, 0], method='BFGS')

print(f"仓库最优位置: ({res.x[0]:.2f}, {res.x[1]:.2f})")
print(f"最小距离平方和: {res.fun:.2f}")
# 输出: (2.00, 1.50), 13.00
```

**scipy.optimize 常用求解器**：

| 求解器 | 适用 | 梯度需求 | 约束支持 |
|--------|------|----------|----------|
| `BFGS` / `L-BFGS-B` | 光滑无约束 / 有界约束 | 不需要 | 边界 |
| `SLSQP` | 一般约束 NLP | 不需要 | 等式/不等式 |
| `trust-constr` | 大规模约束 | 建议提供 | 等式/不等式/边界 |
| `Nelder-Mead` | 非光滑 | 不需要 | 无 |

**国赛常考变体**：参数拟合（最小二乘）、最优控制、结构优化设计、反应动力学参数估计

### 2.3 二次规划 (Quadratic Programming, QP)

**适用场景**：二次目标 + 线性约束 — 投资组合优化、SVM、模型预测控制

**经典案例 — Markowitz 投资组合**：

```
min  ½ x^T Σ x         (风险——方差)
s.t. μ^T x ≥ r_min     (收益下限)
     1^T x = 1          (权重和=1)
     x ≥ 0
```

Python 求解：

```python
"""
用途: 二次规划 — 投资组合优化
输入: 期望收益、协方差矩阵、最低收益要求
输出: 最优投资权重
"""
import cvxpy as cp
import numpy as np

n = 4
mu = np.array([0.12, 0.08, 0.15, 0.05])          # 期望收益
Sigma = np.array([[0.10, 0.02, 0.01, 0.00],       # 协方差
                  [0.02, 0.08, 0.00, 0.01],
                  [0.01, 0.00, 0.20, 0.02],
                  [0.00, 0.01, 0.02, 0.05]])
r_min = 0.10                                       # 最低要求收益

x = cp.Variable(n)
objective = cp.Minimize(cp.quad_form(x, Sigma))
constraints = [mu @ x >= r_min, cp.sum(x) == 1, x >= 0]
prob = cp.Problem(objective, constraints)
prob.solve()

for i, v in enumerate(x.value):
    print(f"资产{i+1}: {v*100:.1f}%")
print(f"最小风险: {prob.value:.4f}")
```

### 2.4 凸优化

**核心优势**：局部最优 = 全局最优，求解高效稳定

**判断凸性**：
- 目标函数 f(x) 是凸函数（Hessian 半正定）
- 约束函数 gi(x) 是凸函数（约束集是凸集）

**国赛应用**：很多问题可通过变形转化为凸优化 → 保证全局最优解
- 最小二乘拟合 → 凸
- LASSO/岭回归 → 凸
- 最大熵模型 → 凸
- 一些几何问题（如最小覆盖圆）→ 凸

## 三、整数优化方法

### 3.1 整数规划 (Integer Programming, IP)

**适用场景**：变量必须取整数（人数、车辆数、设备台数）

**核心思想**：
```
连续LP → LP最优解 → 不是整数?
                     ↓
            分支定界 / 割平面 / 隐枚举
                     ↓
               整数最优解
```

**经典案例 — 下料问题**：

> 有 7m 长的钢管，需截取 2.5m 的 100 根和 1.6m 的 150 根。问最少需要多少根 7m 钢管？

Python 求解（pulp）：

```python
"""
用途: 整数规划 — 钢管下料问题
输入: 原材料长度、需求件数和长度
输出: 最少原材料根数和截取方案
"""
import pulp

# 原材料 7m, 需求 2.5m x100 + 1.6m x150
raw_len = 7
demands = [(2.5, 100), (1.6, 150)]

# 枚举所有可行截取模式
patterns = []
for a in range(int(raw_len / 2.5) + 1):
    for b in range(int(raw_len / 1.6) + 1):
        if a * 2.5 + b * 1.6 <= raw_len:
            patterns.append((a, b))
patterns = patterns[1:]  # 去掉空模式 (0,0)

# IP 建模
prob = pulp.LpProblem("CuttingStock", pulp.LpMinimize)
x = [pulp.LpVariable(f"x{i}", lowBound=0, cat='Integer')
     for i in range(len(patterns))]

prob += pulp.lpSum(x)

for j, (demand_len, demand_qty) in enumerate(demands):
    prob += pulp.lpSum(patterns[i][j] * x[i]
                       for i in range(len(patterns))) >= demand_qty

prob.solve(pulp.PULP_CBC_CMD(msg=False))

print(f"最少用料: {int(pulp.value(prob.objective))} 根")
print("截取方案:")
for i, xi in enumerate(x):
    if pulp.value(xi) > 0.5:
        print(f"  模式{patterns[i]}: {int(pulp.value(xi))} 根")
```

**国赛常考变体**：下料问题、背包问题、选址问题、车辆路径问题 (VRP)

### 3.2 0-1 整数规划 (Binary Integer Programming, BIP)

**适用场景**：决策变量只能取 0 或 1（选/不选、开/关、建/不建）

**经典案例 — 投资项目选择**：

> 公司有 500 万资金，4 个候选项目。各项目投资额和预期收益如下，问选哪些？
>
> | 项目 | 投资(万) | 收益(万) |
> |------|---------|---------|
> | 1    | 200     | 80      |
> | 2    | 150     | 60      |
> | 3    | 180     | 70      |
> | 4    | 100     | 45      |

建模：
```
max  80x1 + 60x2 + 70x3 + 45x4
s.t. 200x1 + 150x2 + 180x3 + 100x4 ≤ 500
     x1, x2, x3, x4 ∈ {0, 1}
```

Python 求解：

```python
"""
用途: 0-1整数规划 — 投资项目选择
输入: 投资额、预期收益、资金上限
输出: 最优选择方案
"""
import pulp

invest = [200, 150, 180, 100]
profit = [80, 60, 70, 45]
budget = 500

prob = pulp.LpProblem("ProjectSelect", pulp.LpMaximize)

x = [pulp.LpVariable(f"x{i}", cat='Binary') for i in range(1, 5)]

prob += pulp.lpSum(p * x[i] for i, p in enumerate(profit))
prob += pulp.lpSum(invest[i] * x[i] for i in range(4)) <= budget
# 额外约束示例: 项目1和项目3互斥
# prob += x[0] + x[2] <= 1

prob.solve(pulp.PULP_CBC_CMD(msg=False))

selected = [i+1 for i in range(4) if pulp.value(x[i]) > 0.5]
print(f"选择项目: {selected}")
print(f"总收益: {int(pulp.value(prob.objective))} 万")
print(f"总投入: {sum(invest[i-1] for i in selected)} 万")
```

**国赛常考变体**：选址-分配问题、集合覆盖、背包问题、设施选址、排班问题

### 3.3 混合整数规划 (Mixed Integer Programming, MIP)

**适用场景**：部分变量为整数、部分为连续 — 国赛中最常见

**经典案例 — 带固定成本的选址-运输问题**：

> 在 m 个候选地点中选部分建仓库（有固定成本），服务 n 个客户。每个仓库有容量限制。求选址+运输的最优方案。

建模：
```
min  Σ f_j·y_j + Σ c_ij·x_ij       (固定成本+运输成本)
s.t. Σ x_ij = d_i   ∀i             (满足需求)
     Σ x_ij ≤ Q_j·y_j  ∀j         (仓库容量)
     x_ij ≥ 0  (连续)
     y_j ∈ {0, 1}  (整数)
```

## 五、优化建模在国赛中的使用流程

```
实际问题
    ↓
① 识别：是不是优化问题？
    → 有目标（最大化/最小化）+ 有约束 + 有决策变量 → 是
    ↓
② 建模：
    → 决策变量：哪些量需要决定？（连续/整数/0-1？）
    → 目标函数：要最大化什么？最小化什么？
    → 约束条件：资源限制、物理规律、逻辑关系？
    ↓
③ 定类：
    → 线性？→ LP/MIP
    → 非线性但凸？→ 凸优化
    → 非线性非凸？→ 智能算法（GA/PSO/模拟退火）← 另见其他笔记
    → 有整数变量？→ IP/MIP
    ↓
④ 求解：选合适的求解器
    ↓
⑤ 验证：最优解合理吗？敏感度分析？
```

## 六、常见陷阱与对策

| 陷阱 | 现象 | 对策 |
|------|------|------|
| **LP解不是整数** | 四舍五入会破坏约束 | 改为 MIP 建模，不要手动画整 |
| **初始值敏感** | NLP 每次结果不同 | 多起点启动，或用全局优化算法 |
| **无可行解** | 求解器报 infeasible | 检查约束是否过紧，考虑松弛 |
| **无界解** | 目标值趋近无穷 | 检查是否遗漏关键约束 |
| **维数灾难** | IP/MIP 求解极慢 | 加启发式、设置时间限制、用松弛+修复 |
| **数值不稳定** | 解差异大 | 变量归一化、约束放缩 |

## 七、编程手速查代码模板

### 通用 LP 模板

```python
from scipy.optimize import linprog

c = [...]          # 目标系数 (min c^T x)
A = [[...],[...]]  # 不等式约束左端
b = [...]          # 不等式约束右端
A_eq = [[...]]     # 等式约束左端 (可选)
b_eq = [...]       # 等式约束右端 (可选)
bounds = [(0,None) for _ in c]  # 变量范围

res = linprog(c, A_ub=A, b_ub=b, A_eq=A_eq, b_eq=b_eq,
              bounds=bounds, method='highs')
print(res.x, res.fun)
```

### 通用 MIP 模板

```python
import pulp

prob = pulp.LpProblem("name", pulp.LpMinimize)  # 或 LpMaximize

# 整数变量
x = pulp.LpVariable("x", lowBound=0, cat='Integer')
# 0-1变量
y = pulp.LpVariable("y", cat='Binary')
# 连续变量
z = pulp.LpVariable("z", lowBound=0)

# 目标
prob += 2*x + 3*y + z

# 约束
prob += x + y >= 5
prob += x - 3*z <= 10

prob.solve(pulp.PULP_CBC_CMD(msg=False))
print(f"x={pulp.value(x)}, y={pulp.value(y)}, z={pulp.value(z)}")
print(f"最优值={pulp.value(prob.objective)}")
```
