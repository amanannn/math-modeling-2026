## 一、何时需要智能优化算法？

传统优化方法（梯度下降、单纯形、内点法）在以下场景失效：

```
失效场景                      → 推荐智能算法
──────────────────────────────────────────────────────
目标函数不可导/不连续/有噪声     → 模拟退火(SA)、遗传算法(GA)
变量离散且规模大（NP-hard）      → 遗传算法(GA)、蚁群算法(ACO)
多峰函数（很多局部最优）         → 粒子群(PSO)、差分进化(DE)
目标函数是"黑箱"（无解析形式）   → 任意元启发式
约束复杂、可行域非凸             → 遗传算法(GA)、差分进化(DE)
组合爆炸（TSP、VRP、排程）      → 蚁群算法(ACO)、遗传算法(GA)
```

### 国赛中的经典应用场景

| 赛题类型 | 具体例子 | 适合算法 |
|----------|---------|---------|
| 路径规划 | 车辆路径(VRP)、旅行商(TSP) | GA, ACO, SA |
| 调度排程 | 车间调度、排课、航班分配 | GA, PSO, SA |
| 选址布局 | 设施选址、物流中心 | GA, PSO |
| 参数优化 | 神经网络权重、模型调参 | PSO, DE, SA |
| 工程设计 | 桁架优化、切削参数 | GA, PSO |
| 组合拍卖 | 频谱分配、资源分配 | GA, ACO |
| 图像分割 | 阈值分割、聚类中心优化 | PSO, GA |

## 二、遗传算法 (Genetic Algorithm, GA)

### 2.1 核心思想

模仿自然进化过程：**选择 → 交叉 → 变异 → 迭代**

```
种群初始化 (随机生成 N 个个体)
    ↓
┌─ 适应度评估 (fitness function)
│   ↓
│  选择 (轮盘赌/锦标赛) → 保留优秀个体
│   ↓
│  交叉 (crossover) → 交换基因片段
│   ↓
│  变异 (mutation) → 随机扰动基因
│   ↓
│  新一代种群
└── 反复迭代直到满足终止条件
    ↓
最优解输出
```

**关键参数**：

| 参数 | 典型值 | 说明 |
|------|--------|------|
| 种群大小 `pop_size` | 50~200 | 太小易早熟，太大计算慢 |
| 交叉概率 `crossover_rate` | 0.7~0.9 | 控制搜索强度 |
| 变异概率 `mutation_rate` | 0.01~0.1 | 控制多样性，太大变随机搜索 |
| 迭代次数 `max_gen` | 100~500 | 视问题复杂度调整 |
| 编码方式 | 二进制/实数/排列 | 连续问题用实数，组合问题用排列编码 |

### 2.2 手写实数编码 GA 求解函数最小值

```python
"""
用途: 手写遗传算法 — 求 f(x)=x*sin(10πx)+2, x∈[-1,2] 的最大值
输入: 适应度函数、变量范围、种群参数
输出: 最优解和最优值 + 收敛曲线
"""
import numpy as np
import matplotlib.pyplot as plt

plt.rcParams['font.sans-serif'] = ['SimHei']
plt.rcParams['axes.unicode_minus'] = False

# ---------- 目标函数 ----------
def fitness(x):
    """求最大值: f(x) = x * sin(10πx) + 2"""
    return x * np.sin(10 * np.pi * x) + 2

# ---------- 初始化种群 ----------
def init_population(pop_size, n_vars, lb, ub):
    return np.random.uniform(lb, ub, size=(pop_size, n_vars))

# ---------- 选择：锦标赛 ----------
def tournament_selection(pop, fit_scores, k=3):
    idx = np.random.choice(len(pop), k, replace=False)
    best_idx = idx[np.argmax(fit_scores[idx])]
    return pop[best_idx].copy()

# ---------- 交叉：模拟二进制交叉 (SBX) ----------
def sbx_crossover(p1, p2, eta=15):
    """SBX 算子, eta 控制子代与父代的接近程度"""
    n = len(p1)
    c1, c2 = p1.copy(), p2.copy()
    for i in range(n):
        if np.random.rand() < 0.5:
            if abs(p1[i] - p2[i]) < 1e-10:
                continue
            u = np.random.rand()
            beta = (2*u)**(1/(eta+1)) if u <= 0.5 else (1/(2*(1-u)))**(1/(eta+1))
            c1[i] = 0.5 * ((1+beta)*p1[i] + (1-beta)*p2[i])
            c2[i] = 0.5 * ((1-beta)*p1[i] + (1+beta)*p2[i])
    return c1, c2

# ---------- 变异：多项式变异 ----------
def polynomial_mutation(child, lb, ub, eta_m=20, mutation_rate=0.1):
    for i in range(len(child)):
        if np.random.rand() < mutation_rate:
            r = np.random.rand()
            delta = min(child[i]-lb, ub-child[i]) / (ub - lb)
            if r < 0.5:
                delta_q = (2*r + (1-2*r)*(1-delta)**(eta_m+1))**(1/(eta_m+1)) - 1
            else:
                delta_q = 1 - (2*(1-r) + 2*(r-0.5)*(1-delta)**(eta_m+1))**(1/(eta_m+1))
            child[i] += delta_q * (ub - lb)
            child[i] = np.clip(child[i], lb, ub)
    return child

# ---------- 主 GA 循环 ----------
def ga_maximize(fitness_func, n_vars, lb, ub,
                pop_size=100, max_gen=200, crossover_rate=0.85,
                mutation_rate=0.08, elite_ratio=0.05):
    """
    GA 主函数
    返回: (best_x, best_f, history)
    """
    # 初始化
    pop = init_population(pop_size, n_vars, lb, ub)
    n_elite = max(1, int(pop_size * elite_ratio))
    history = []

    for gen in range(max_gen):
        # 适应度评估
        fit = np.array([fitness_func(ind) for ind in pop])

        # 精英保留
        elite_idx = np.argsort(fit)[-n_elite:]

        # 新种群
        new_pop = []

        while len(new_pop) < pop_size:
            p1 = tournament_selection(pop, fit)
            p2 = tournament_selection(pop, fit)
            if np.random.rand() < crossover_rate:
                c1, c2 = sbx_crossover(p1, p2)
            else:
                c1, c2 = p1.copy(), p2.copy()
            c1 = polynomial_mutation(c1, lb, ub, mutation_rate=mutation_rate)
            c2 = polynomial_mutation(c2, lb, ub, mutation_rate=mutation_rate)
            new_pop.append(c1)
            if len(new_pop) < pop_size:
                new_pop.append(c2)

        new_pop = np.array(new_pop)

        # 精英替换最差个体
        new_fit = np.array([fitness_func(ind) for ind in new_pop])
        worst_idx = np.argsort(new_fit)[:n_elite]
        for i, ei in enumerate(elite_idx):
            new_pop[worst_idx[i]] = pop[ei].copy()

        pop = new_pop
        history.append(fit.max())

    # 最终最优
    fit_final = np.array([fitness_func(ind) for ind in pop])
    best_idx = np.argmax(fit_final)
    best_x = pop[best_idx]
    best_f = fit_final[best_idx]

    return best_x, best_f, history

# ---------- 运行 ----------
best_x, best_f, history = ga_maximize(
    fitness, n_vars=1, lb=-1, ub=2,
    pop_size=80, max_gen=150
)
print(f"GA 最优解: x={best_x[0]:.6f}")
print(f"GA 最优值: f(x)={best_f[0]:.6f}")

# 收敛曲线
plt.figure(figsize=(8, 4))
plt.plot(history, 'b-', linewidth=1.5)
plt.xlabel('迭代次数')
plt.ylabel('最优适应度')
plt.title('GA 收敛曲线')
plt.grid(True, alpha=0.3)
plt.tight_layout()
plt.savefig(r'D:\虚拟C盘\数学建模培训\output\GA_convergence.png', dpi=150)
plt.show()
```

## 三、粒子群优化 (Particle Swarm Optimization, PSO)

### 3.1 核心思想

模拟鸟群觅食：每个粒子在搜索空间中飞行，同时记住自己的历史最优位置和群体的全局最优位置。

```
初始化粒子位置和速度（随机）
    ↓
┌─ 评估每个粒子的适应度
│   ↓
│  更新个体最优 pbest（每个粒子自己的最优）
│   ↓
│  更新全局最优 gbest（全体最优）
│   ↓
│  更新速度: v = w·v + c1·r1·(pbest-x) + c2·r2·(gbest-x)
│   ↓
│  更新位置: x = x + v
└── 反复迭代
    ↓
输出 gbest
```

**速度更新公式**（标准 PSO）：

```
v_id^(t+1) = ω·v_id^t + c1·r1·(pbest_id - x_id^t) + c2·r2·(gbest_d - x_id^t)
```

| 参数 | 含义 | 典型值 |
|------|------|--------|
| ω (inertia weight) | 惯性权重，平衡探索与开发 | 0.4~0.9（通常线性递减） |
| c1 (cognitive) | 认知系数，粒子向自己历史最优学习 | 1.5~2.0 |
| c2 (social) | 社会系数，粒子向全局最优学习 | 1.5~2.0 |
| v_max | 速度上限，防止粒子飞过头 | 0.1~0.5 × 搜索范围 |

### 3.2 手写 PSO 求解

```python
"""
用途: 手写粒子群优化 — 求 Schwefel 函数最小值
       f(x) = Σ[-x_i * sin(√|x_i|)], x_i ∈ [-500, 500]
       全局最小值在 (420.9687,...,420.9687)
输入: 目标函数、维度、搜索范围
输出: 最优解、最优值、收敛曲线
"""
import numpy as np
import matplotlib.pyplot as plt

plt.rcParams['font.sans-serif'] = ['SimHei']
plt.rcParams['axes.unicode_minus'] = False

def schwefel(x):
    """Schwefel 函数 — 多峰、欺骗性强"""
    return np.sum(-x * np.sin(np.sqrt(np.abs(x))))

def pso_minimize(func, n_vars, lb, ub,
                 n_particles=50, max_iter=200,
                 w_start=0.9, w_end=0.4, c1=1.5, c2=1.5):
    """
    PSO 主函数（最小化）
    返回: (best_x, best_f, history)
    """
    dim = n_vars
    # 初始化
    pos = np.random.uniform(lb, ub, (n_particles, dim))
    vel = np.random.uniform(-0.1*(ub-lb), 0.1*(ub-lb), (n_particles, dim))

    pbest_pos = pos.copy()
    pbest_val = np.array([func(p) for p in pos])

    gbest_idx = np.argmin(pbest_val)
    gbest_pos = pbest_pos[gbest_idx].copy()
    gbest_val = pbest_val[gbest_idx]

    history = []

    for t in range(max_iter):
        # 线性递减惯性权重
        w = w_start - (w_start - w_end) * t / max_iter

        for i in range(n_particles):
            r1, r2 = np.random.rand(dim), np.random.rand(dim)
            # 速度更新
            vel[i] = (w * vel[i]
                      + c1 * r1 * (pbest_pos[i] - pos[i])
                      + c2 * r2 * (gbest_pos - pos[i]))
            # 速度限制
            vel[i] = np.clip(vel[i], -0.2*(ub-lb), 0.2*(ub-lb))
            # 位置更新
            pos[i] = pos[i] + vel[i]
            pos[i] = np.clip(pos[i], lb, ub)

            # 评估
            val = func(pos[i])
            if val < pbest_val[i]:
                pbest_val[i] = val
                pbest_pos[i] = pos[i].copy()
            if val < gbest_val:
                gbest_val = val
                gbest_pos = pos[i].copy()

        history.append(gbest_val)

    return gbest_pos, gbest_val, history

# 运行 PSO（2 维 Schwefel）
best_x, best_f, history = pso_minimize(
    schwefel, n_vars=2, lb=-500, ub=500,
    n_particles=80, max_iter=200
)
print(f"PSO 最优解: x={best_x}")
print(f"PSO 最优值: f(x)={best_f:.4f}")
# 理论最优: (420.97, 420.97), f ≈ -837.97

# 收敛曲线
plt.figure(figsize=(8, 4))
plt.semilogy(history, 'r-', linewidth=1.5)
plt.xlabel('迭代次数')
plt.ylabel('最优值 (log)')
plt.title('PSO 收敛曲线 — Schwefel 函数')
plt.grid(True, alpha=0.3)
plt.tight_layout()
plt.savefig(r'D:\虚拟C盘\数学建模培训\output\PSO_convergence.png', dpi=150)
plt.show()
```

## 四、模拟退火 (Simulated Annealing, SA)

### 4.1 核心思想

模拟金属退火过程：高温时粒子剧烈运动（大范围搜索），随温度降低逐渐稳定（局部精调）。

**核心：以一定概率接受劣解**，避免陷入局部最优。

```
初始化: 随机解 x₀, 初始温度 T₀, 降温率 α
    ↓
┌─ 产生邻域解 x' = x + Δ (随机扰动)
│   ↓
│  ΔE = f(x') - f(x)        # 能量变化
│   ↓
│  if ΔE < 0:               # 更优 → 接受
│      x = x'
│  else:                     # 更差 → 概率接受
│      p = exp(-ΔE / T)
│      if rand < p: x = x'
│   ↓
│  T = α · T                # 降温
└── 反复直到 T < T_min
    ↓
输出最优解
```

**关键参数**：

| 参数 | 典型值 | 说明 |
|------|--------|------|
| 初始温度 T₀ | 100~10000 | 足够高，初期接受大部分劣解 |
| 降温率 α | 0.85~0.99 | 越接近 1 越精细但越慢 |
| 终止温度 T_min | 1e-3~1e-8 | 太低则浪费计算 |
| 马尔可夫链长 L | 100~500 | 每个温度下的迭代次数 |
| 邻域扰动步长 | 0.01~0.1 × 范围 | 太小收敛慢，太大不稳定 |

### 4.2 scipy.optimize.dual_annealing 使用

SciPy 内置的 SA 实现，推荐在国赛中直接使用。

```python
"""
用途: scipy dual_annealing 求解多峰函数全局最小值
输入: 目标函数、变量边界
输出: 最优解和最优值
"""
from scipy.optimize import dual_annealing
import numpy as np

# Rastrigin 函数 — 大量局部极小，经典测试函数
def rastrigin(x):
    n = len(x)
    return 10*n + sum(xi**2 - 10*np.cos(2*np.pi*xi) for xi in x)

# 2 维 Rastrigin, x_i ∈ [-5.12, 5.12]
bounds = [(-5.12, 5.12), (-5.12, 5.12)]

result = dual_annealing(
    rastrigin,
    bounds,
    maxiter=1000,
    initial_temp=5230,      # 初始温度
    restart_temp_ratio=2e-5, # 重启温度比
    seed=42
)

print(f"SA 最优解: x={result.x}")
print(f"SA 最优值: f(x)={result.fun:.6f}")
print(f"迭代次数: {result.nfev}")
# 理论最优: (0,0), f=0
```

## 五、差分进化 (Differential Evolution, DE)

### 5.1 核心思想

DE 是 GA 的一种变体，用 **差分向量** 代替交叉算子，对连续优化特别高效。

```
DE/rand/1/bin 流程：

对于每个个体 x_i:
  ① 从种群中随机选 3 个不同的个体 a, b, c
  ② 变异: v = a + F × (b - c)    (F 是缩放因子, 0.5~0.9)
  ③ 交叉: u_j = v_j 若 rand ≤ CR 否则 x_ij  (CR 交叉概率)
  ④ 选择: 若 u 优于 x_i 则保留 u 否则 x_i
```

### 5.2 scipy.optimize.differential_evolution 使用

```python
"""
用途: scipy differential_evolution 求解全局最小值
输入: 目标函数、变量边界
输出: 最优解和最优值
"""
from scipy.optimize import differential_evolution
import numpy as np

# Ackley 函数 — 大量局部极小
def ackley(x):
    a, b, c = 20, 0.2, 2*np.pi
    n = len(x)
    sum1 = sum(xi**2 for xi in x)
    sum2 = sum(np.cos(c*xi) for xi in x)
    return (-a * np.exp(-b * np.sqrt(sum1/n))
            - np.exp(sum2/n) + a + np.exp(1))

bounds = [(-32, 32), (-32, 32)]

result = differential_evolution(
    ackley,
    bounds,
    strategy='best1bin',       # 变异策略
    maxiter=1000,
    popsize=15,                # 种群大小倍数
    mutation=(0.5, 1.0),       # 缩放因子范围
    recombination=0.7,         # 交叉概率 CR
    seed=42
)

print(f"DE 最优解: x={result.x}")
print(f"DE 最优值: f(x)={result.fun:.6f}")
print(f"迭代次数: {result.nfev}")
# 理论最优: (0,0), f≈0
```

**DE vs GA 对比**：

| 特性 | DE | GA |
|------|:--:|:--:|
| 编码 | 实数（天然） | 二进制/实数/排列 |
| 变异算子 | 差分向量（自适应强） | 随机扰动 |
| 适合问题 | 连续优化 | 离散/组合优化 |
| 参数数 | 少(F, CR 2个) | 多(交叉率、变异率、选择压力等) |
| 收敛速度 | 较快 | 中等 |
| SciPy 直接可用 | ✅ `differential_evolution` | ❌ 需手写 |

## 六、蚁群算法 (Ant Colony Optimization, ACO)

### 6.1 核心思想

模拟蚂蚁觅食：蚂蚁在路径上留下 **信息素**，短路径信息素积累更快，吸引更多蚂蚁。

```
初始化: 信息素矩阵 τ₀（均匀分布）
    ↓
┌─ 每只蚂蚁根据信息素和启发式信息构建路径
│   p_ij = τ_ij^α · η_ij^β / Σ(τ_ij^α · η_ij^β)
│   ↓
│  评估各蚂蚁路径长度
│   ↓
│  更新信息素:
│    τ_ij = (1-ρ)·τ_ij + ΣΔτ_ij^k  (ρ 为挥发率)
└── 反复迭代
    ↓
输出最优路径
```

| 参数 | 典型值 | 说明 |
|------|--------|------|
| α (信息素权重) | 1~2 | 越大越依赖已有信息 |
| β (启发式权重) | 2~5 | 越大越倾向短边 |
| ρ (挥发率) | 0.1~0.5 | 越大信息素消失越快 |
| 蚂蚁数 m | 城市数~2×城市数 | |

**适用问题**：TSP、VRP、网络路由、任务调度。

**与 GA 对比**：
- ACO 在 TSP/VRP 上通常优于 GA
- ACO 需要问题具有"可构造路径"的结构
- GA 通用性更强

| **局部精调** | 弱 | 强 | 弱 | 中等 | 弱 |

### 7.2 国赛选型决策树

```
问题类型？
├── 连续优化（变量为实数）
│   ├── 目标函数光滑、可求导？→ 传统优化（梯度下降、BFGS、SLSQP）
│   ├── 多峰、不可导、有噪声？
│   │   ├── 维度 < 20？ → SA 或 DE
│   │   └── 维度 ≥ 20？ → PSO 或 DE
│   └── 约束复杂、可行域非凸？→ GA（罚函数处理约束）
│
├── 组合优化（离散变量）
│   ├── 路径类（TSP、VRP）→ ACO 或 GA
│   ├── 调度类（排程、排班）→ GA
│   └── 分配类（背包、选址）→ GA 或 SA
│
└── 混合（既有连续又有整数）
    └── GA 或 SA（混合编码）
```

### 7.3 何时使用传统优化 vs 智能优化

| 场景 | 用传统优化 | 用智能优化 |
|------|-----------|-----------|
| 目标函数是二次型 | ✅ 直接 QP 求解器 | ❌ 杀鸡用牛刀 |
| 线性约束线性目标 | ✅ LP 一秒求解 | ❌ 太慢且不精确 |
| 函数光滑、凸 | ✅ 梯度法确定性高 | ❌ 随机性反而不好 |
| 黑箱、无梯度信息 | ❌ 无法求导 | ✅ 零阶方法刚好 |
| 多峰、需要全局最优 | ❌ 容易陷入局部 | ✅ 概率性跳出 |
| NP-hard 组合问题 | ❌ 指数时间爆炸 | ✅ 近似解足够好 |
| 要求精确解 | ✅ 传统方法 | ❌ 智能算法是近似解 |
| 实时在线优化 | ❌ 迭代慢 | ❌ 也慢，需简化模型 |

> **国赛黄金法则**：能用解析方法（LP/NLP/QP）求出精确解时绝不用智能算法。智能算法的定位是"传统方法做不了时的 Plan B"。

```python
"""
用途: scipy 全局优化 — 通用模板
输入: 目标函数、变量边界
输出: 最优解和最优值
"""
from scipy.optimize import differential_evolution, dual_annealing

# ---------- 目标函数 ----------
def objective(x):
    # x 是 numpy array, 长度为 n_vars
    # 返回标量（最小化！）
    return sum(xi**2 for xi in x)

# 变量边界
bounds = [(-10, 10)] * 3  # 3 维, 每个维度范围 [-10, 10]

# ---------- 方案 1: 差分进化 DE ----------
result_de = differential_evolution(
    objective,
    bounds,
    strategy='best1bin',        # 变异策略
    popsize=15,                 # 种群大小倍数
    mutation=(0.5, 1.0),        # F 缩放因子
    recombination=0.7,          # CR 交叉率
    maxiter=1000,
    tol=1e-7,                   # 收敛容差
    seed=42                     # 可复现
)
print(f"[DE] x={result_de.x}, f={result_de.fun:.6f}")

# ---------- 方案 2: 模拟退火 SA ----------
result_sa = dual_annealing(
    objective,
    bounds,
    maxiter=1000,
    initial_temp=5230,
    seed=42
)
print(f"[SA] x={result_sa.x}, f={result_sa.fun:.6f}")
```

### 模板 B：手写 GA（组合优化，TSP 示例）

```python
"""
用途: GA 求解 TSP — 通用模板
输入: 距离矩阵、种群参数
输出: 最优路径和长度
"""
import numpy as np

# ---------- 问题: TSP ----------
# 随机生成 20 个城市坐标
np.random.seed(42)
n_cities = 20
cities = np.random.rand(n_cities, 2) * 100

def calc_distance(route):
    """计算路径总长度"""
    d = 0
    for i in range(len(route)):
        j = (i + 1) % len(route)
        d += np.linalg.norm(cities[route[i]] - cities[route[j]])
    return d

# ---------- 排列编码 GA ----------
def ga_tsp(dist_func, n_cities, pop_size=100, max_gen=500,
           elite_ratio=0.05, mutation_rate=0.1):
    """GA 求解 TSP 的简易实现"""
    # 初始化：随机排列
    pop = [np.random.permutation(n_cities) for _ in range(pop_size)]
    n_elite = max(1, int(pop_size * elite_ratio))
    history = []

    for gen in range(max_gen):
        # 适应度 = 1/距离（最小化）
        fits = np.array([1.0 / dist_func(route) for route in pop])
        elite_idx = np.argsort(fits)[-n_elite:]

        new_pop = []
        while len(new_pop) < pop_size:
            # 锦标赛选择
            i1, i2 = np.random.choice(pop_size, 2, replace=False, p=fits/fits.sum())
            p1, p2 = pop[i1].copy(), pop[i2].copy()

            # PMX 交叉 (部分映射交叉)
            if np.random.rand() < 0.85:
                a, b = sorted(np.random.randint(0, n_cities, 2))
                c1 = np.full(n_cities, -1)
                c1[a:b] = p1[a:b]
                remaining = [x for x in p2 if x not in c1[a:b]]
                c1[:a] = remaining[:a]
                c1[b:] = remaining[a:]
            else:
                c1 = p1.copy()

            # 交换变异
            if np.random.rand() < mutation_rate:
                a, b = np.random.randint(0, n_cities, 2)
                c1[a], c1[b] = c1[b], c1[a]

            new_pop.append(c1)

        # 精英保留
        new_fits = np.array([1.0 / dist_func(r) for r in new_pop])
        worst_idx = np.argsort(new_fits)[:n_elite]
        for i, ei in enumerate(elite_idx):
            new_pop[worst_idx[i]] = pop[ei].copy()

        pop = new_pop
        best_fit = max(fits)
        history.append(1.0 / best_fit)

    # 最优解
    final_fits = np.array([1.0 / dist_func(r) for r in pop])
    best_route = pop[np.argmax(final_fits)]
    best_len = dist_func(best_route)

    return best_route, best_len, history

# 运行
best_route, best_len, _ = ga_tsp(calc_distance, n_cities)
print(f"GA-TSP 最优长度: {best_len:.2f}")
print(f"最优路径: {best_route}")
```

### 模板 C：手写 PSO（连续优化通用模板）

```python
"""
用途: PSO — 连续优化通用模板
输入: 目标函数、变量维度、搜索范围
输出: 最优解和最优值
"""
import numpy as np

def pso_optimize(func, n_vars, lb, ub,
                 n_particles=50, max_iter=200,
                 w=0.72, c1=1.49, c2=1.49):
    """
    标准 PSO（带惯性权重）
    最小化 func(x)
    """
    dim = n_vars
    span = ub - lb

    # 初始化
    pos = np.random.uniform(lb, ub, (n_particles, dim))
    vel = np.random.uniform(-0.2*span, 0.2*span, (n_particles, dim))

    pbest = pos.copy()
    pbest_val = np.array([func(p) for p in pos])

    gbest_idx = np.argmin(pbest_val)
    gbest = pbest[gbest_idx].copy()
    gbest_val = pbest_val[gbest_idx]

    for _ in range(max_iter):
        for i in range(n_particles):
            r1, r2 = np.random.rand(dim), np.random.rand(dim)
            vel[i] = (w * vel[i]
                      + c1*r1*(pbest[i] - pos[i])
                      + c2*r2*(gbest - pos[i]))
            vel[i] = np.clip(vel[i], -0.2*span, 0.2*span)
            pos[i] += vel[i]
            pos[i] = np.clip(pos[i], lb, ub)

            val = func(pos[i])
            if val < pbest_val[i]:
                pbest_val[i] = val
                pbest[i] = pos[i].copy()
            if val < gbest_val:
                gbest_val = val
                gbest = pos[i].copy()

    return gbest, gbest_val

# 示例使用
def sphere(x):
    return sum(xi**2 for xi in x)

best_x, best_f = pso_optimize(sphere, n_vars=3, lb=-10, ub=10)
print(f"PSO 最优解: {best_x}")
print(f"PSO 最优值: {best_f:.6f}")
```

### 模板 D：手写 SA（组合优化通用模板）

```python
"""
用途: 模拟退火 — 通用模板
输入: 目标函数、初始解、邻域生成函数
输出: 最优解和最优值
"""
import numpy as np

def simulated_annealing(func, x0, neighbor_func,
                        T0=100, T_min=1e-4, alpha=0.95,
                        max_iter_per_T=200, verbose=False):
    """
    通用 SA 框架
    func: 目标函数（最小化）
    x0: 初始解
    neighbor_func(x): 返回 x 的邻域解
    """
    current = np.array(x0, dtype=float)
    best = current.copy()
    current_val = func(current)
    best_val = current_val
    T = T0
    history = [best_val]

    while T > T_min:
        for _ in range(max_iter_per_T):
            candidate = neighbor_func(current)
            candidate_val = func(candidate)
            delta = candidate_val - current_val

            if delta < 0 or np.random.rand() < np.exp(-delta / T):
                current = candidate
                current_val = candidate_val
                if current_val < best_val:
                    best = current.copy()
                    best_val = current_val

        history.append(best_val)
        T *= alpha
        if verbose:
            print(f"T={T:.4f}, best={best_val:.6f}")

    return best, best_val, history

# 示例：求解 f(x)=x²+2sin(5πx)+1, x∈[-2,2]
def my_func(x):
    return x[0]**2 + 2*np.sin(5*np.pi*x[0]) + 1

def my_neighbor(x):
    return x + np.random.uniform(-0.3, 0.3)

best_x, best_f, hist = simulated_annealing(
    my_func, x0=[1.5],
    neighbor_func=my_neighbor,
    T0=100, alpha=0.95, max_iter_per_T=100
)
print(f"SA 最优解: x={best_x[0]:.6f}")
print(f"SA 最优值: f(x)={best_f[0]:.6f}")
```

## 九、国赛避坑指南

| 常见错误 | 正确做法 |
|---------|---------|
| 盲目用智能算法取代传统优化 | 先判断是否是凸/线性问题 → 能用精确解就用精确解 |
| 参数不调直接用默认 | 至少跑 5 次看稳定性，必要时做参数敏感性分析 |
| 不收敛就猛加迭代 | 先调参数（种群大小、变异率等），不要只加迭代次数 |
| 结果不稳定但只跑一次 | 智能算法本质随机，至少跑 10 次取平均或最优 |
| 代码太复杂国赛写不完 | 优先用 scipy 内置算法，手写留到最后 |
| 没有对比基线 | 至少和简单启发式（如贪心）对比，证明智能算法有效 |

---

> 智能优化算法的本质是 **用时间换全局性**——在传统方法无能为力时，通过随机搜索+启发式策略找到足够好的解。国赛中，先想清楚"这个问题传统方法能不能做"，再决定是否动用智能算法。SciPy 的 `differential_evolution` 和 `dual_annealing` 是第一选择，手写 GA/PSO 作为补充。记住：**比赛不是研究算法，是用算法解决问题**。
