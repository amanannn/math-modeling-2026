## 一、决策问题分类

```
决策问题
├── 确定型决策（条件已知）
│   ├── 单目标 → 直接比较
│   └── 多目标 → 评价函数法、目标规划
│
├── 风险型决策（概率已知）
│   ├── 期望值法
│   ├── 决策树
│   └── 贝叶斯决策
│
├── 不确定型决策（概率未知）
│   ├── 乐观准则 (max-max)
│   ├── 悲观准则 (max-min)
│   ├── 折中准则 (Hurwicz)
│   ├── 后悔值准则 (Savage)
│   └── 等概率准则 (Laplace)
│
└── 对抗型决策（博弈）
    ├── 二人零和博弈
    └── 纳什均衡
```

## 二、不确定型决策 —— 五种准则

### 经典案例

> 某公司推新产品，有 3 种方案。市场状态有 4 种可能（很好/好/一般/差），概率未知。收益矩阵如下：

| 方案 | 很好 | 好 | 一般 | 差 |
|------|:----:|:--:|:----:|:--:|
| A1   | 800  | 550 | 300  | -100 |
| A2   | 600  | 500 | 350  | 0   |
| A3   | 400  | 380 | 320  | 150 |

```python
"""
用途: 五种不确定型决策准则求解
输入: 收益矩阵 (行=方案, 列=状态)
输出: 五种准则下的最优方案
"""
import numpy as np

payoff = np.array([
    [800, 550, 300, -100],   # A1
    [600, 500, 350,    0],   # A2
    [400, 380, 320,  150]    # A3
])
n_alt, n_state = payoff.shape
names = ['A1', 'A2', 'A3']

# 1. 乐观准则 (max-max): 每个方案取最好情况, 选最好的
optimistic = payoff.max(axis=1)
print(f"乐观准则 → {names[optimistic.argmax()]}: 收益={optimistic.max()}")

# 2. 悲观准则 (max-min): 每个方案取最坏情况, 选最不坏的
pessimistic = payoff.min(axis=1)
print(f"悲观准则 → {names[pessimistic.argmax()]}: 收益={pessimistic.max()}")

# 3. 折中准则 (Hurwicz, alpha=0.6 偏乐观)
alpha = 0.6
hurwicz = alpha * payoff.max(axis=1) + (1-alpha) * payoff.min(axis=1)
print(f"折中准则(alpha={alpha}) → {names[hurwicz.argmax()]}: 值={hurwicz.max():.1f}")

# 4. 后悔值准则 (Savage / min-max regret)
regret = payoff.max(axis=0) - payoff          # 后悔矩阵
max_regret = regret.max(axis=1)               # 每方案最大后悔
print(f"后悔值准则 → {names[max_regret.argmin()]}: 最大后悔={max_regret.min()}")

# 5. 等概率准则 (Laplace)
laplace = payoff.mean(axis=1)
print(f"等概率准则 → {names[laplace.argmax()]}: 期望={laplace.max():.1f}")
```

**五种准则的选择建议**：

| 准则 | 心态 | 适用场景 |
|------|------|----------|
| 乐观 | 激进 | 新兴市场、高回报领域 |
| 悲观 | 保守 | 事关生存的重大决策 |
| 折中 | 可调 | α 反映决策者态度 |
| 后悔值 | 稳健 | 事后不后悔 |
| 等概率 | 中性 | 完全无信息时 |

## 三、风险型决策 —— 决策树

### 经典案例

> 公司决定是否开发新产品。开发成本 50 万。市场好(概率 0.6)赚 200 万，市场差(概率 0.4)亏 80 万。不开发则 0 收益。另外可选择先做市场调研(成本 10 万)，调研准确率 80%。

```python
"""
用途: 决策树分析 — 新产品开发决策
输入: 决策节点、机会节点、概率、收益
输出: 各路径期望值和最优决策
"""
import numpy as np

# 简化：不调研直接决策
p_good, p_bad = 0.6, 0.4
cost_dev = 50

# 开发分支
ev_develop = p_good * (200 - cost_dev) + p_bad * (-80 - cost_dev)
# 不开发
ev_skip = 0

print(f"开发期望值: {ev_develop:.1f} 万")
print(f"不开发期望值: {ev_skip} 万")
print(f"最优决策: {'开发' if ev_develop > ev_skip else '不开发'}")
# 期望值 = 38 万 > 0 → 开发

# 带调研的贝叶斯更新（略去完整计算，核心逻辑如下）
# P(好|调研好) = P(调研好|好)*P(好) / P(调研好)
# 贝叶斯公式更新后验概率 → 重新计算 EV
```

**决策树通用步骤**：
1. 画树：□ 决策节点 → ○ 机会节点 → △ 结果
2. 从右向左逆向计算期望值
3. 在决策节点选 max（或 min）
4. 剪枝：划掉被淘汰的分支

## 四、层次分析法 (AHP)

### 核心思想

把复杂决策问题分解为 **目标 → 准则 → 方案** 三层，通过两两比较确定权重。

### 步骤

```
① 建立层次结构
   目标层：选最优方案
   准则层：成本、质量、时间……
   方案层：A、B、C

② 构造判断矩阵 (1~9标度)
   两两比较准则的重要性

③ 计算权重（特征向量法）
   判断矩阵最大特征值对应的特征向量 → 归一化 → 权重

④ 一致性检验
   CR = CI/RI < 0.1 → 通过，否则调整判断矩阵

⑤ 逐层合成总权重 → 排序
```

```python
"""
用途: AHP 层次分析法完整实现
输入: 判断矩阵 (n×n numpy array)
输出: 权重向量 + 一致性检验结果
"""
import numpy as np

def ahp(matrix, labels=None):
    """单层 AHP: 判断矩阵 → 权重 + CR"""
    n = matrix.shape[0]
    eigenvalues, eigenvectors = np.linalg.eig(matrix)
    max_idx = np.argmax(eigenvalues.real)
    lambda_max = eigenvalues[max_idx].real
    w = eigenvectors[:, max_idx].real
    w = w / w.sum()  # 归一化

    CI = (lambda_max - n) / (n - 1) if n > 1 else 0
    # 平均随机一致性指标 RI
    RI_dict = {1:0, 2:0, 3:0.52, 4:0.89, 5:1.12, 6:1.26,
               7:1.36, 8:1.41, 9:1.46, 10:1.49}
    RI = RI_dict.get(n, 1.49)
    CR = CI / RI if RI != 0 else 0

    result = {
        'weights': w,
        'lambda_max': lambda_max,
        'CI': CI,
        'CR': CR,
        'consistent': CR < 0.1
    }
    if labels:
        for lb, wt in zip(labels, w):
            print(f"  {lb}: {wt:.4f}")
    print(f"  lambda_max={lambda_max:.3f}, CI={CI:.4f}, CR={CR:.4f}")
    print(f"  一致性: {'通过' if result['consistent'] else '不通过'}")
    return result

# 示例：准则层判断矩阵
#        成本 质量 时间
#  成本 [  1    3    5  ]
#  质量 [ 1/3   1    3  ]
#  时间 [ 1/5  1/3   1  ]
A_criteria = np.array([
    [1,   3,   5],
    [1/3, 1,   3],
    [1/5, 1/3, 1]
])
print("准则层权重:")
result = ahp(A_criteria, labels=['成本', '质量', '时间'])
# 输出: 成本≈0.63, 质量≈0.26, 时间≈0.11, CR≈0.03 < 0.1 通过
```

### AHP 判断矩阵标度 (Saaty 1~9)

| 标度 | 含义 |
|:----:|------|
| 1 | 同等重要 |
| 3 | 稍微重要 |
| 5 | 明显重要 |
| 7 | 强烈重要 |
| 9 | 极端重要 |
| 2,4,6,8 | 中间值 |

## 五、TOPSIS 法

### 核心思想

最优方案 = 离正理想解最近 + 离负理想解最远

### 步骤

```
① 原始矩阵 X (m方案 × n指标)
② 正向化：极小型/中间型/区间型 → 极大型
③ 标准化：zij = xij / sqrt(Σxij²)
④ 确定正理想解 Z+ 和负理想解 Z-
⑤ 计算各方案到 Z+ 和 Z- 的欧氏距离 D+, D-
⑥ 计算相对贴近度 C = D- / (D+ + D-)
⑦ 按 C 排序
```

```python
"""
用途: TOPSIS 综合评价
输入: 原始数据矩阵 (行=方案, 列=指标), 指标方向列表
输出: 各方案得分和排序
"""
import numpy as np

def topsis(X, directions):
    """
    X: m×n 矩阵
    directions: 长度 n 的列表，1=极大型，-1=极小型，
                0=中间型(需先转换为极大型)
    """
    m, n = X.shape
    # 正向化：极小型取倒数或 max-x
    X_pos = X.copy()
    for j in range(n):
        if directions[j] == -1:
            X_pos[:, j] = X[:, j].max() - X[:, j]
        # 中间型、区间型需另外处理，此处略

    # 标准化 (向量归一化)
    Z = X_pos / np.sqrt((X_pos ** 2).sum(axis=0))

    # 正负理想解
    Z_plus = Z.max(axis=0)
    Z_minus = Z.min(axis=0)

    # 距离
    D_plus = np.sqrt(((Z - Z_plus) ** 2).sum(axis=1))
    D_minus = np.sqrt(((Z - Z_minus) ** 2).sum(axis=1))

    # 贴近度
    C = D_minus / (D_plus + D_minus)
    rank = np.argsort(-C) + 1  # 从大到小排名

    return C, rank

# 示例：4个方案，3个指标（都是极大型）
X = np.array([
    [8, 7, 9],
    [6, 8, 7],
    [9, 6, 8],
    [7, 9, 6]
])
scores, ranks = topsis(X, directions=[1, 1, 1])
for i in range(4):
    print(f"方案{i+1}: 得分={scores[i]:.4f}, 排名={ranks[i]}")
```

## 六、熵权法

**思想**：指标的变异程度越大 → 信息量越大 → 权重越大

```python
"""
用途: 熵权法计算客观权重
输入: m×n 数据矩阵
输出: 各指标权重
"""
import numpy as np

def entropy_weight(X):
    m, n = X.shape
    # 归一化
    P = X / X.sum(axis=0)
    P = np.where(P == 0, 1e-12, P)  # 避免 log(0)

    # 熵值
    e = -np.sum(P * np.log(P), axis=0) / np.log(m)
    # 差异系数 → 权重
    d = 1 - e
    w = d / d.sum()
    return w

X = np.array([[8,7,9],[6,8,7],[9,6,8],[7,9,6]])
w = entropy_weight(X)
for i, wi in enumerate(w):
    print(f"指标{i+1} 权重: {wi:.4f}")
```

> **AHP vs 熵权法**：AHP 是主观赋权（依赖专家判断），熵权法是客观赋权（依赖数据本身）。国赛中推荐 **AHP + 熵权法 组合赋权**：最终权重 = α × 主观权重 + (1-α) × 客观权重，既体现专家经验又反映数据特征。

## 七、模糊综合评价 (FCE)

**思想**：处理无法精确量化的评价（如"服务好"→ 隶属度 0.7）

```
步骤：
① 建立评价因素集 U = {u1, u2, ...}
② 建立评语集 V = {优, 良, 中, 差}
③ 确定因素权重 A (AHP/熵权)
④ 构造模糊评价矩阵 R (每个因素对各评语的隶属度)
⑤ 模糊合成 B = A ∘ R
⑥ 按最大隶属度原则/加权平均 确定最终等级
```

## 八、决策方法选型速查

| 问题特征 | 推荐方法 | 关键输出 |
|----------|----------|----------|
| 多方案多指标比优劣 | **TOPSIS** | 排序得分 |
| 需确定指标权重(主观) | **AHP** | 权重向量 |
| 需确定指标权重(客观) | **熵权法** | 客观权重 |
| 指标模糊难量化 | **模糊综合评价** | 等级判断 |
| 概率已知，需权衡 | **决策树** | 期望值 + 最优路径 |
| 概率未知，需稳健 | **不确定准则** | 五种准则下的选择 |
| 多目标有优先级 | **目标规划** | 分层满意解 |
| 多人博弈对抗 | **博弈论** | 纳什均衡 |

---

> 决策模型的核心不是公式，而是**把实际问题结构化**：方案(Alternatives)、状态(States)、收益(Payoffs)、准则(Criteria)。这四个元素理清楚，方法自然就出来了。国赛中 AHP+TOPSIS 是最常见的组合拳——一个定权重、一个定排序。
