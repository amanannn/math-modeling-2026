# 其余课程——拓宽眼界的一句话

> 这些课不深学，但遇到赛题能想起来"好像有这个方法"就够了。

---

## 理论思维类

| 课程 | 一句话（懂了什么） |
|------|-------------------|
| 1.2 数模相关理论知识 | 数学建模 ≠ 套公式——先搞清楚问题是"描述性的/预测性的/优化性的"，不同类型对应完全不同的数学工具 |
| 1.7 AIDC诊断理论 | 故障诊断的核心思想：正常状态建模型 → 偏离即异常，这个"异常检测"思路可以迁移到金融风控、设备预警等赛题 |
| 1.15 2017A题剖析 | CT重建的本质是"从投影反推原图"的逆问题，而逆问题几乎都有不适定性——你需要正则化来约束解，这是所有反演类问题的通用套路 |

## 优化扩展类

| 课程 | 一句话（懂了什么） |
|------|-------------------|
| 1.16/1.24 最优化模型 | 优化问题的核心不是"怎么解"而是"怎么建"——把实际问题翻译成目标函数+约束条件的能力比算法更重要；另外，凸优化问题有全局最优保证，非凸问题只能找局部最优 |
| 1.8 智能优化与强化学习 | 强化学习 = agent 通过试错学习最优策略（状态→动作→奖励→更新），不是单纯的优化算法，而是一种"决策框架"；当问题涉及序贯决策（多步决策相互影响）时，RL 比单步优化更适用 |

## 专业应用类（拓宽你的模型武器库）

| 课程 | 一句话（懂了什么） |
|------|-------------------|
| 1.5 生物生态学数学模型 | 生态学模型的核心思想是"相互作用"——竞争/捕食/共生都可以用微分方程组描述，这和经济学中的市场竞争模型、化学反应动力学是完全相通的 |
| 1.9 计算电磁学 | 电磁场问题太大了，但 Maxwell 方程组有两个简化方向：低频近似→静场（Poisson方程），高频近似→射线（几何光学）；数模中绝大多数电磁题不是在考你电磁学，是考你"知道什么时候用什么近似" |
| 1.22 马氏过程 | 马尔可夫性的核心一句话：**未来只取决于现在，不取决于过去**。排队论、PageRank、MCMC采样、隐马尔可夫模型（语音识别）全部基于这个思想，极其通用 |
| 1.23 机器人路径规划 | 这本质是"带约束的图搜索"——A* 算法是 Dijkstra 的启发式升级版（加个估计函数引导方向），RRT 是随机采样的树生长法（适合高维空间），遇到路径规划题别只知道最短路 |

## 数据/预测类

| 课程 | 一句话（懂了什么） |
|------|-------------------|
| 1.21 机器学习用于材料预测 | 材料科学的"成分→性能"预测本质上就是个回归问题，和任何"输入→输出"的预测题一样——特征工程（选什么作为输入特征）比模型选择更影响最终效果 |

## 论文写作类（编程手也要听一耳朵）

| 课程 | 一句话（懂了什么） |
|------|-------------------|
| 1.18 优秀论文剖析 | 国赛好论文的共同特点：摘要300字把"我们做了什么→用了什么方法→得到什么结果→有什么亮点"讲清楚；正文不堆公式，每个公式前后都有文字解释"为什么用"和"得到什么" |
| 1.19/1.20 论文写作 | 论文写作最大的坑：图表没自明性（脱离正文看不懂）→ 评委翻到你的图发现没标注单位/图例/说明 = 扣分，这是最亏的失分点 |
| 1.17 2024B赛题讲评 | 真题复盘的真正价值：你以为自己的解法没问题，一看讲评才发现漏了关键约束/假设不合理/模型验证不够——这种"what could go wrong"的感觉比学新算法更重要 |

## 经验/工具类

| 课程 | 一句话（懂了什么） |
|------|-------------------|
| 1.4 AIGC赋能 | AI 工具的核心用法不是"让它替你做题"，而是"让它帮你快速探索可能性"——拿到题目先让 AI 列出 10 种可能的建模方向，你再从中筛选 |
| 1.13 大模型简析 | LLM = 基于概率预测下一个词，它没有"理解"也没有"推理"，所以用它做数学推导不如用它做文献综述/代码辅助/写作润色 |
| 1.25/1.26 国奖经验 | 所有国奖队伍的共识：① 72小时最后4小时用来检查而不是赶工 ② 模型不要追求复杂，简单模型+严谨验证 > 复杂模型+糊弄验证 ③ 摘要要反复改，评委第一眼定生死 |
| 1.27 25国赛A | 待定 |

## 线上资源——各模块一句话

| 模块 | 一句话了解 |
|------|-----------|
| 3.5 数据分析实验设计 | 方差分析 (ANOVA) 的核心思想：把总变异拆成"组间差异"和"组内随机误差"，判断分组是否有意义 |
| 3.6 多元统计 | 主成分分析 (PCA) = 高维数据降维的第一选择；蒙特卡洛 = 大量随机采样→统计逼近，适用于无法解析求解的问题 |
| 3.7 预测与随机过程 | 时间序列的核心：趋势 + 周期 + 随机波动的分解；排队论：用生灭过程算等待时间/队列长度，服务系统优化必备 |
| 3.10 数值计算 | 数值计算的通用问题：舍入误差 + 截断误差 + 稳定性，不是算出来就对了 |
| 3.11 不确定性建模 | 模糊数学的核心：不精确 ≠ 错——用隶属度代替"是/否"的硬分类，适合评价和决策类问题 |
| 3.14 博弈论 | 纳什均衡的核心：每个玩家在给定别人策略下做了最优选择，结果却不一定是全局最优——囚徒困境是经典例子 |
| 4.5 优秀论文 | 建议只看最近5年的 (2020-2024)，太老的风格和现在要求不一致 |
| 4.6 竞赛题点评 | 校内赛 ≈ 国赛的缩小版，提前练手用校内赛数据跑一遍完整流程 |
