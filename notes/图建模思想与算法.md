## 一、什么是"图建模"？

**核心思想**：把实际问题抽象为 **节点 + 边** 的结构，然后调用图论算法求解。

```
现实问题                      图模型                   算法求解
────────                    ─────────                ────────
城市道路网   ─────────→   节点=路口, 边=道路    ──→   最短路
社交关系     ─────────→   节点=人,   边=好友    ──→   社区发现
任务调度     ─────────→   节点=任务, 边=依赖    ──→   拓扑排序
物流配送     ─────────→   节点=地点, 边=路径    ──→   TSP/VRP
电路布局     ─────────→   节点=元件, 边=连线    ──→   最小割
```

**一句话**：如果你能画出一个"点+线"的示意图来描述问题，那就可以用图论。

## 二、图建模的核心优势

### 2.1 为什么图建模在数模中如此强大？

| 优势 | 说明 | 数模中的体现 |
|------|------|-------------|
| **直观** | 点+线天然贴近空间/关系直觉 | 评委能快速理解你的建模思路 |
| **通用** | 一张图能承载无数种语义 | 交通、通信、社交、物流全可用 |
| **算法丰富** | 图论经过 300 年发展，算法库极其成熟 | 最短路径、最大流、最小生成树……拿来即用 |
| **可扩展** | 边加权、点加权、有向/无向、多层图 | 同一个框架适应问题变体 |
| **可验证** | 图算法有严格的正确性保证 | 不用像启发式那样担心局部最优 |
| **可视化** | 图天然适合可视化呈现 | 论文里放一张网络图，比公式更有说服力 |

### 2.2 图建模 vs 数学规划

| 对比维度 | 图建模 | 数学规划（LP/MIP） |
|----------|--------|-------------------|
| 适用问题 | 关系型、网络型、连通型 | 资源分配型、生产计划型 |
| 建模难度 | 低（画图即可） | 中（需列约束） |
| 求解速度 | 快（多项式时间） | 不一定（NP-hard 需启发式） |
| 表达力 | 侧重拓扑结构 | 侧重数值约束 |
| 典型算法 | Dijkstra, Kruskal, Ford-Fulkerson | Simplex, Branch-and-Bound |

> **国赛经验**：很多问题可以同时用图建模 + 数学规划两种方式求解，形成互补验证——论文里这是加分项。

## 三、图建模的"翻译"技巧

### 3.1 常见翻译表

| 实际问题中的概念 | 对应图模型中的概念 |
|----------------|------------------|
| 地点、位置、站点 | **节点 (Node/Vertex)** |
| 道路、线路、连接、关系 | **边 (Edge)** |
| 距离、时间、费用 | **边权重 (Edge Weight)** |
| 城市/设施容量 | **节点权重 (Node Weight)** |
| 单行道、依赖方向 | **有向边 (Directed Edge)** |
| 两种不同类型的实体 | **二分图 (Bipartite Graph)** |
| 层次结构 | **树 (Tree)** |
| 需要遍历所有点 | **哈密顿路/回路** |
| 需要遍历所有边 | **欧拉路/回路** |
| 起点→终点 | **最短路径** |
| 连接所有点最省钱 | **最小生成树** |
| 最大输送能力 | **最大流** |
| 分割两类东西 | **最小割** |

## 四、经典图算法与数模案例

### 4.1 最短路问题 (Shortest Path)

**核心算法**：
| 算法 | 适用 | 复杂度 |
|------|------|--------|
| Dijkstra | 非负权图 | O((V+E)·log V) |
| Floyd-Warshall | 全源最短路 | O(V³) |
| Bellman-Ford | 含负权边 | O(V·E) |
| A* | 有启发信息 | O(E) 实际 |

**数模案例 — 灾后物资配送路径规划**：

> 地震后有 n 个受灾点需要从物资中心配送。已知各点之间的距离/通行时间，求到每个点的最快路线。

```python
"""
用途: 最短路径 — 物资配送路径规划
输入: 节点列表、带权边列表、起点
输出: 到各点的最短路径和距离
"""
import networkx as nx
import matplotlib.pyplot as plt

G = nx.Graph()
# 添加带权边：(节点1, 节点2, 距离)
edges = [
    ('中心', 'A', 10), ('中心', 'B', 15), ('中心', 'C', 25),
    ('A', 'B', 8),  ('A', 'D', 20), ('B', 'C', 12),
    ('B', 'D', 14), ('C', 'D', 18), ('C', 'E', 10),
    ('D', 'E', 6),  ('D', 'F', 15), ('E', 'F', 8)
]
G.add_weighted_edges_from(edges)

# Dijkstra：单源最短路
paths = nx.single_source_dijkstra_path(G, source='中心', weight='weight')
dists = nx.single_source_dijkstra_path_length(G, source='中心', weight='weight')

for node in sorted(dists.keys()):
    if node != '中心':
        route = ' → '.join(paths[node])
        print(f"中心 → {node}: 距离={dists[node]}, 路径={route}")

# 可视化
pos = nx.spring_layout(G, seed=42)
nx.draw(G, pos, with_labels=True, node_color='lightblue',
        edge_color='gray', node_size=800, font_size=10)
labels = nx.get_edge_attributes(G, 'weight')
nx.draw_networkx_edge_labels(G, pos, edge_labels=labels)
plt.title("灾后物资配送网络")
plt.savefig('output/shortest_path.png', dpi=300, bbox_inches='tight')
```

**国赛变体**：带时间窗的最短路、多目标最短路（距离+风险）、动态路网（边权随时变化）

### 4.2 最小生成树 (Minimum Spanning Tree, MST)

**核心算法**：
| 算法 | 特点 |
|------|------|
| Prim | 适合稠密图 O(V²) 或 O(E·logV) |
| Kruskal | 适合稀疏图 O(E·logE)，需要并查集 |

**数模案例 — 光纤布线最小成本**：

> 在 n 个村庄之间铺设光纤，已知任意两村之间的铺设成本。求连接所有村庄的最小总成本方案。

```python
"""
用途: 最小生成树 — 光纤布线优化
输入: 节点列表、边(成本)列表
输出: MST 边集合和总成本
"""
import networkx as nx

G = nx.Graph()
villages = ['A','B','C','D','E','F']
edges = [('A','B',5),('A','C',8),('A','D',12),('B','C',6),
         ('B','E',10),('C','D',7),('C','E',9),('C','F',11),
         ('D','F',8),('E','F',5)]
G.add_weighted_edges_from(edges)

mst = nx.minimum_spanning_tree(G, weight='weight', algorithm='kruskal')

total = sum(d['weight'] for _, _, d in mst.edges(data=True))
print(f"MST 总成本: {total}")
print("铺设方案:")
for u, v, d in mst.edges(data=True):
    print(f"  {u} ── {v}: 成本={d['weight']}")
```

**国赛变体**：带约束的 Steiner 树（允许增加中继点）、度受限 MST

### 4.3 网络流 (Network Flow)

**核心问题**：在容量网络中，从源点到汇点最多能运多少？

**经典算法**：
| 算法 | 核心思想 | 复杂度 |
|------|---------|--------|
| Ford-Fulkerson | 不断找增广路 | O(E·f_max) |
| Edmonds-Karp | BFS 找最短增广路 | O(V·E²) |
| Dinic | 分层图 + 阻塞流 | O(V²·E) |

**数模案例 — 供水管网最大输送能力**：

> 城市供水网络，每条管道有容量上限(m³/h)。求从水库到城区的最大供水量。

```python
"""
用途: 最大流 — 供水管网最大输送能力
输入: 有向容量图、源点、汇点
输出: 最大流量和各边实际流量
"""
import networkx as nx

G = nx.DiGraph()
# 边: (起点, 终点, 容量)
edges = [
    ('水库', 'A', 20), ('水库', 'B', 15),
    ('A', 'B', 8),    ('A', 'C', 15),
    ('B', 'C', 10),   ('B', 'D', 12),
    ('C', '城区', 25),('D', '城区', 18),
    ('A', 'D', 5)
]
G.add_weighted_edges_from(edges, weight='capacity')

# 最大流
flow_val, flow_dict = nx.maximum_flow(G, '水库', '城区', capacity='capacity')
print(f"最大供水量: {flow_val} m³/h")
print("各管段实际流量:")
for u in flow_dict:
    for v, f in flow_dict[u].items():
        if f > 0:
            print(f"  {u} → {v}: {f}/{G[u][v]['capacity']} m³/h")
```

**国赛变体**：最小费用最大流（效率+成本双目标）、多商品流、带节点容量的流

### 4.4 拓扑排序 (Topological Sort)

**适用**：有依赖关系且无环的任务排序（AOV 网）

**数模案例 — 工程项目工序安排**：

> 某工程有 7 道工序，部分工序有先后依赖。求可行施工顺序。

```python
"""
用途: 拓扑排序 — 工序依赖调度
输入: 任务列表和依赖关系
输出: 可行执行顺序
"""
import networkx as nx

tasks = ['打地基','砌墙','架梁','水电安装','内装','外装','验收']
deps = [('打地基','砌墙'), ('打地基','架梁'), ('砌墙','水电安装'),
        ('架梁','水电安装'), ('水电安装','内装'), ('水电安装','外装'),
        ('砌墙','外装'), ('内装','验收'), ('外装','验收')]

G = nx.DiGraph()
G.add_nodes_from(tasks)
G.add_edges_from(deps)

order = list(nx.topological_sort(G))
print("施工顺序:", ' → '.join(order))
# 注意：拓扑排序不唯一，这里给出一种可行方案

# 同时求关键路径（最长路径，决定总工期）
# 可手动设置各工序耗时后用 nx.dag_longest_path
```

**国赛变体**：带资源约束的调度、关键路径法 (CPM)、PERT 三时估计

### 4.5 旅行商问题 (TSP) 与车辆路径问题 (VRP)

**TSP**：访问所有城市恰好一次回到起点，最小化总路程（NP-hard）
**VRP**：多辆车，每辆有容量，服务所有客户（更贴近实际物流）

**数模案例 — 快递收件路线优化**：

```python
"""
用途: TSP 近似求解 — 快递收件路线（最近邻启发式）
输入: 城市坐标
输出: 访问顺序和总里程
注意: TSP 是 NP-hard，小规模可用精确算法，大规模用启发式
"""
import networkx as nx
import numpy as np
from scipy.spatial.distance import pdist, squareform

# 10个点坐标
np.random.seed(42)
coords = np.random.rand(10, 2) * 100

# 构建完全图
D = squareform(pdist(coords))
G = nx.Graph()
for i in range(len(coords)):
    for j in range(i+1, len(coords)):
        G.add_edge(i, j, weight=D[i][j])

# 最近邻启发式
def nearest_neighbor_tsp(G, start=0):
    n = G.number_of_nodes()
    unvisited = set(G.nodes())
    unvisited.remove(start)
    tour = [start]
    current = start
    total = 0

    while unvisited:
        next_node = min(unvisited, key=lambda v: G[current][v]['weight'])
        total += G[current][next_node]['weight']
        unvisited.remove(next_node)
        tour.append(next_node)
        current = next_node

    total += G[current][start]['weight']  # 回到起点
    tour.append(start)
    return tour, total

tour, dist = nearest_neighbor_tsp(G)
print(f"TSP 路线: {tour}")
print(f"总里程: {dist:.2f}")

# 注：小规模TSP (<20点) 可用 nx.approximation.traveling_salesman_problem
# 或 pulp/cvxpy 建立 MIP 精确求解
```

**国赛常考**：CVRP（带容量约束的VRP）、VRPTW（带时间窗）、带充电站的电动车路径

### 4.6 最小割 (Minimum Cut)

**核心思想**：用最小的代价把图"切开"，分成两个不相连通的部分。

**数模案例 — 图像分割 / 社交网络拆分**：

```python
"""
用途: 最小割 — 网络最脆弱环节分析
输入: 容量图、源点、汇点
输出: 最小割的边集
"""
import networkx as nx

G = nx.DiGraph()
G.add_weighted_edges_from([
    ('S', 'A', 10), ('S', 'B', 5), ('A', 'B', 4),
    ('A', 'C', 9), ('B', 'D', 8), ('C', 'D', 6),
    ('C', 'T', 10), ('D', 'T', 10)
], weight='capacity')

cut_val, (S_set, T_set) = nx.minimum_cut(G, 'S', 'T', capacity='weight')
print(f"最小割容量: {cut_val}")
print(f"S侧节点: {S_set}, T侧节点: {T_set}")

# 列出割边
cut_edges = [(u, v) for u in S_set for v in G.successors(u)
             if v in T_set]
print(f"割边: {cut_edges}")
```

### 4.7 二分图匹配 (Bipartite Matching)

**适用**：两类不同实体间的配对问题

**数模案例 — 任务分配 / 导师-学生双向选择**：

```python
"""
用途: 二分图最大匹配 — 人员-任务最优分配
输入: 二分图
输出: 最大匹配方案
"""
import networkx as nx

B = nx.Graph()
workers = ['甲', '乙', '丙', '丁']
tasks = ['任务1', '任务2', '任务3', '任务4']
B.add_nodes_from(workers, bipartite=0)
B.add_nodes_from(tasks, bipartite=1)

# 每个工人能胜任的任务
compatible = [('甲','任务1'),('甲','任务2'),('乙','任务1'),
              ('乙','任务3'),('丙','任务2'),('丙','任务4'),
              ('丁','任务3'),('丁','任务4')]
B.add_edges_from(compatible)

matching = nx.bipartite.maximum_matching(B)
print("最大匹配:")
for w in workers:
    if w in matching:
        print(f"  {w} → {matching[w]}")
```

## 六、图建模在国赛中的判断流程

```
读题
  ↓
问题里有"路径/网络/连通/配送/布局/依赖/管道/布线/遍历"？
  ↓ 是                            ↓ 否
可以图建模                    可能不需要图论（用LP/统计/微分方程）
  ↓
问自己三个问题：
① 节点是什么？（地点？人？任务？设备？）
② 边代表什么？（道路？关系？依赖？管线？）
③ 边权重代表什么？（距离？时间？费用？容量？）
  ↓
回答清楚这三问 → 图模型就建好了
  ↓
选算法：
- 找最优路线 → 最短路/TSP
- 找最小连接方案 → MST
- 找最大输送能力 → 最大流
- 找最少断点 → 最小割
- 工序排期 → 拓扑排序+关键路径
- 配对分配 → 二分图匹配
  ↓
networkx 实现 + 可视化 → 论文成图
```
