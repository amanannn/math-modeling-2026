## 二、核心方程

### 2.1 Maxwell 方程组（时域形式）

```
Faraday 定律:   ∇ × E = -∂B/∂t
Ampere 定律:    ∇ × H = J + ∂D/∂t
Gauss 电定律:   ∇ · D = ρ
Gauss 磁定律:   ∇ · B = 0
```

本构关系：`D = εE`, `B = μH`, `J = σE`

### 2.2 派生方程

| 方程 | 形式 | 适用 |
|------|------|------|
| **波动方程** | ∇2E - με·∂2E/∂t2 = 0 | 电磁波传播、天线辐射 |
| **Helmholtz 方程** | ∇2E + k2E = 0 | 频域、稳态波动 |
| **Poisson 方程** | ∇2φ = -ρ/ε | 静电场 |
| **Laplace 方程** | ∇2φ = 0 | 无源静电场 |
| **扩散方程** | ∇2H = μσ·∂H/∂t | 导体中的涡流 |
| **Biot-Savart 定律** | dB = μ0·Idl×r/(4πr3) | 线电流产生的磁场 |

### 2.3 简化是关键

真实 Maxwell 方程组是全耦合的、7 维度的（3 空间 + 3 场分量 + 时间）。数模解题的核心是**根据问题特征做简化**：

| 简化条件 | 结果 |
|----------|------|
| 频率低、尺寸小 | 准静态近似 → Poisson/Laplace + Biot-Savart |
| 无源、远场 | Helmholtz 方程 |
| 一维传播 | 一维波动方程（解析可解） |
| 轴对称 | 二维柱坐标（降维） |
| 稳态 | d/dt = 0 → 静场方程 |

## 三、数值方法

### 3.1 FDTD（时域有限差分）— Yee 元胞法

**核心思想**：E 和 H 在空间和时间上交错取样，直接离散 Maxwell 旋度方程。

```
特征：
- 显式递推，不需要解矩阵
- 时域，一次仿真得到宽带响应
- 稳定性条件：c·Δt ≤ 1/sqrt(1/Δx2 + 1/Δy2 + 1/Δz2)
- 适用范围最广
```

```python
"""
用途: 一维 FDTD — 电磁波在介质中的传播
输入: 空间步长、时间步长、介质参数
输出: 电场随时间的演化
"""
import numpy as np
import matplotlib.pyplot as plt

# 参数
nx = 200; nt = 500
dx = 0.01  # m
dt = dx / (2 * 3e8)  # Courant 条件
eps0 = 8.854e-12; mu0 = 4e-7 * np.pi

# 场初始化
Ez = np.zeros(nx)
Hy = np.zeros(nx-1)

# 激励源（中心点加高斯脉冲）
source_pos = nx // 4
t0 = 30; spread = 10

results = []
for n in range(nt):
    # 更新 Hy (磁场的旋度方程离散)
    Hy += dt / mu0 * (Ez[1:] - Ez[:-1]) / dx
    # 更新 Ez (电场)
    Ez[1:-1] += dt / eps0 * (Hy[1:] - Hy[:-1]) / dx
    # 激励
    Ez[source_pos] += np.exp(-0.5 * ((n - t0) / spread) ** 2)
    if n % 50 == 0:
        results.append((n, Ez.copy()))

plt.figure(figsize=(10, 5))
for n, ez in results:
    plt.plot(np.arange(nx)*dx, ez + n*0.02, 'b-', alpha=0.7)
plt.xlabel('x (m)'); plt.ylabel('Ez')
plt.title('1D FDTD: 电磁脉冲传播')
plt.savefig('output/fdtd_1d.png', dpi=300)
```

### 3.2 FEM（有限元法）

**核心思想**：区域分片，每个单元内用简单基函数逼近，组装成大型稀疏矩阵求解。

**优势**：处理复杂几何形状、非均匀介质
**劣势**：需要网格生成、矩阵求解，实现复杂

### 3.3 MoM（矩量法）

**核心思想**：积分方程 → 离散为矩阵方程。适合天线、散射等开域问题。

**特点**：只离散物体表面（不是整个空间），未知数少，但矩阵是稠密的。

### 3.4 方法选择速查

| 问题特征 | 推荐方法 | 理由 |
|----------|----------|------|
| 波传播/天线（时域） | **FDTD** | 直观、显式、宽带 |
| 不规则形状、静场 | **FEM** | 灵活几何 |
| 天线辐射、散射（频域） | **MoM** | 只离散表面 |
| 规则区域、教学 | **FDM** | 简单、容易验证 |

## 四、国赛/美赛中简化建模的技巧

### 4.1 天线覆盖问题 → 简化为几何+路径损耗

> 不需要跑 FDTD！用 Friis 传输方程 + 自由空间路径损耗模型即可。

```
接收功率: Pr = Pt + Gt + Gr - L(d)
路径损耗: L(d) = 20·log10(d) + 20·log10(f) - 147.55  (dB)
```

### 4.2 电磁屏蔽 → 简化为传输线模型 + 趋肤效应

```
屏蔽效能 SE (dB) = R + A + M
R: 反射损耗 ≈ 168 + 10·log(σr / (μr·f))
A: 吸收损耗 ≈ 1.314·t·sqrt(f·μr·σr)  (t=厚度mm)
```

### 4.3 无线充电 → 简化为耦合电感电路

```
效率 η = k2·Q1·Q2 / (1 + sqrt(1 + k2·Q1·Q2))2
k: 耦合系数, Q: 品质因数
```

用等效电路代替场求解，把电磁问题降维为电路问题。

### 4.4 磁悬浮 → 简化为 Earnshaw 定理 + 力的平衡

```
F_magnetic ∝ B2·A / (2·μ0)   (电磁力估算)
用受力平衡条件 + 稳定性分析，不必解 PDE
```

### 均匀直线阵的方向图

> 等间距 d、等幅同相的 N 个天线排成一线，求远场方向图。

```python
"""
用途: 天线阵列方向图计算 (阵列因子)
输入: 阵元数 N, 间距 d, 波长 lambda
输出: 方向图
"""
import numpy as np
import matplotlib.pyplot as plt

N = 8                    # 阵元数
d = 0.5                  # 间距 (波长归一化)
theta = np.linspace(-np.pi/2, np.pi/2, 1000)

# 阵列因子: AF = sin(N·ψ/2) / sin(ψ/2), ψ = 2π·d·sinθ
psi = 2 * np.pi * d * np.sin(theta)
AF = np.abs(np.sin(N * psi / 2) / (N * np.sin(psi / 2) + 1e-12))
AF_dB = 20 * np.log10(AF + 1e-12)

plt.figure(figsize=(10, 5))

# 极坐标方向图
ax1 = plt.subplot(121, projection='polar')
```

## 七、编程手核心备忘

```python
# ===== 常用物理常数 =====
from scipy.constants import epsilon_0, mu_0, c, pi
# epsilon_0 = 8.854e-12 F/m
# mu_0 = 1.257e-6 N/A2
# c = 2.998e8 m/s

# ===== 自由空间波阻抗 =====
eta_0 = np.sqrt(mu_0 / epsilon_0)  # ≈ 377 Ω

# ===== Friis 传输方程 (dB) =====
def path_loss_db(d, f):
    """自由空间路径损耗, d(m), f(Hz)"""
    return 20*np.log10(d) + 20*np.log10(f) - 147.55

# ===== 趋肤深度 =====
def skin_depth(f, sigma, mu_r=1):
    """趋肤深度, f(Hz), sigma(S/m)"""
    return np.sqrt(1 / (pi * f * mu_0 * mu_r * sigma))

# ===== 偶极子天线远场 =====
def dipole_pattern(theta):
    """半波偶极子远场方向图"""
    return np.abs(np.cos(pi/2 * np.cos(theta)) / np.maximum(np.sin(theta), 1e-12))
```

## 八、国赛电磁类题目的解题策略

```
拿到电磁相关题目
    ↓
① 判断：是传播/辐射/静场/耦合？
    ↓
② 简化：
   低频 + 小尺寸 → 准静态 + 电路等效
   远场 + 传播 → 射线模型 + 路径损耗
   只需要趋势 → 解析近似公式 (Friis, Biot-Savart)
   必须精确 → 数值方法 (FDTD / FEM)
    ↓
③ 选工具：
   电路模型 → 手算 / sympy
   几何/射线 → numpy + 自行编码
   场求解 → meep / scikit-fem
    ↓
④ 输出论文中展示：
   方向图、场分布图、S参数曲线、效率随频率变化
```

---

> 电磁场题目在国赛中不常见，但出现就是区分度。核心策略：**能简化就不要解全 Maxwell 方程**——把场问题降维成路问题、把波动问题降维成几何问题。真要数值求解时，一维/二维 FDTD 用 numpy 手写就够，别上来就装 FEniCS。
