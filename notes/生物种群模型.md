## 二、种群增长模型

### 2.1 Malthusian 模型（指数增长）

**基本假设**：种群增长率与当前种群数量成正比。

**微分方程**：
```
dN/dt = r * N
N(t) = N0 * exp(r * t)      (解析解)
```

其中 `r` 为内禀增长率（出生率 - 死亡率）。

**Python 实现**：

```python
"""
用途: Malthusian (指数增长) 模型数值求解与解析解对比
输入: 初始种群 N0, 增长率 r, 时间区间 t_span
输出: 数值解 vs 解析解对比图
"""
import numpy as np
from scipy.integrate import solve_ivp
import matplotlib.pyplot as plt

def malthus(t, N, r):
    """Malthusian 增长: dN/dt = r*N"""
    return r * N

# 参数设置
r = 0.3            # 年增长率 30%
N0 = 10.0          # 初始种群
t_span = [0, 30]   # 30 年

# 数值求解
sol = solve_ivp(malthus, t_span, [N0], args=(r,),
                method='RK45', max_step=0.1, dense_output=True)

# 解析解
t_fine = np.linspace(0, 30, 300)
N_exact = N0 * np.exp(r * t_fine)

# 可视化
plt.figure(figsize=(10, 5))
plt.plot(sol.t, sol.y[0], 'ro', markersize=3, label='数值解 (solve_ivp)')
plt.plot(t_fine, N_exact, 'b-', linewidth=1.5, label=f'解析解 N(t)={N0:.0f}*exp({r}t)')
plt.xlabel('时间 (年)'); plt.ylabel('种群数量 N')
plt.title('Malthusian 指数增长模型')
plt.legend(); plt.grid(True, alpha=0.3)

# 标注 r 的含义
plt.text(0.7, 0.95, f'增长率 r={r}', transform=plt.gca().transAxes,
         bbox=dict(boxstyle='round', facecolor='wheat', alpha=0.5))
plt.savefig('output/malthusian_model.png', dpi=300)
print(f"30 年后种群: {sol.y[0,-1]:.0f} (解析解: {N_exact[-1]:.0f})")
```

**局限性**：指数增长 → 无穷大，不符合有限资源现实。短期可近似（如细菌培养早期）。

### 2.2 Logistic 模型（阻滞增长）

**基本假设**：环境容量 `K` 限制了最大种群，增长率随种群接近 `K` 而下降。

**微分方程**：
```
dN/dt = r * N * (1 - N/K)
```

**解析解**（可分离变量）：
```
N(t) = K / (1 + (K/N0 - 1) * exp(-r*t))
```

**关键特征**：
- N << K 时 → 近似指数增长
- N = K/2 时 → 增长速率最大
- N → K 时 → 增长趋于 0

```python
"""
用途: Logistic (阻滞增长) 模型
输入: N0, r, K; 输出: N(t) 曲线及特征标注
"""
import numpy as np
from scipy.integrate import solve_ivp
import matplotlib.pyplot as plt

def logistic(t, N, r, K):
    """Logistic 增长: dN/dt = r*N*(1 - N/K)"""
    return r * N * (1 - N / K)

# 参数
r = 0.5          # 内禀增长率
K = 100.0        # 环境容量
N0 = 2.0        # 初始种群

sol = solve_ivp(logistic, [0, 20], [N0], args=(r, K),
                method='RK45', max_step=0.05, dense_output=True)

t_fine = np.linspace(0, 20, 500)
N_numerical = sol.sol(t_fine)[0]
# 解析解
N_analytic = K / (1 + (K/N0 - 1) * np.exp(-r * t_fine))

plt.figure(figsize=(10, 6))
plt.plot(t_fine, N_numerical, 'b-', linewidth=2, label='数值解')
plt.plot(t_fine, N_analytic, 'r--', linewidth=1.5, alpha=0.7, label='解析解')
plt.axhline(K, color='gray', linestyle=':', linewidth=1, label=f'环境容量 K={K}')
plt.axhline(K/2, color='orange', linestyle='--', linewidth=1, alpha=0.6,
            label=f'最大增长点 K/2={K/2}')
plt.xlabel('时间 t'); plt.ylabel('种群数量 N(t)')
plt.title('Logistic 种群增长模型')
plt.legend(); plt.grid(True, alpha=0.3)
plt.savefig('output/logistic_model.png', dpi=300)
```

**模型对比表**：

| 模型 | 方程 | 平衡点 | 长期行为 | 适用场景 |
|------|------|:------:|:--------:|----------|
| Malthusian | `dN/dt = rN` | N=0 (不稳定) | 指数爆炸 | 短期/无限资源 |
| Logistic | `dN/dt = rN(1-N/K)` | N=0 (不稳定), N=K (稳定) | 趋向 K | 有限资源种群 |

**数模应用案例**：
- 中国人口预测：历史数据拟合 r 和 K，预测峰值人口
- 微生物培养：确定最大产量 K 和倍增时间
- 新技术扩散：将 N 视为采用者数量，K 为市场总量

## 三、多物种相互作用模型

### 3.1 Lotka-Volterra 捕食者-猎物模型

**基本假设**：
- 猎物 (prey, x) 在无捕食者时指数增长
- 捕食者 (predator, y) 在无猎物时指数死亡
- 捕食速率正比于相遇概率 (x*y)

**微分方程组**：
```
dx/dt =  a*x - b*x*y      (猎物)
dy/dt =  d*x*y - c*y      (捕食者)
```

其中：
- a: 猎物种内增长率
- b: 捕食效率
- d: 猎物→捕食者转化率 (d = e*b, e 为转化效率)
- c: 捕食者死亡率

**平衡点**：
```
P1 = (0, 0)               — 两者灭绝（鞍点）
P2 = (c/d, a/b)           — 非零平衡点（中心）

在 P2 处：J = [[a - b*y,  -b*x],
              [ d*y,    d*x - c]]
代入 P2：J = [[0,     -b*c/d],
             [a*d/b,  0]]
特征值：λ = ±i*sqrt(a*c)  → 纯虚根 → 中心点（周期振荡）
```

```python
"""
用途: Lotka-Volterra 捕食者-猎物模型
包含: 时间序列图 + 相图 + 守恒量验证
"""
import numpy as np
from scipy.integrate import solve_ivp
import matplotlib.pyplot as plt

def lotka_volterra(t, z, a, b, c, d):
    """Lotka-Volterra 方程"""
    x, y = z
    dx = a * x - b * x * y
    dy = d * x * y - c * y
    return [dx, dy]

# 参数 (经典值)
a, b, c, d = 1.0, 0.1, 0.5, 0.02

# 多个初值 → 不同周期轨道
initial_conditions = [
    (40, 9),   # 基准
    (30, 15),  # 多捕食者
    (50, 5),   # 多猎物
    (20, 20),  # 均衡接近
]

colors = ['b', 'r', 'g', 'orange']
fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(14, 5))

for i, (x0, y0) in enumerate(initial_conditions):
    sol = solve_ivp(lotka_volterra, [0, 150], [x0, y0],
                    args=(a, b, c, d), max_step=0.2)

    # 时间序列 (子图1)
    ax1.plot(sol.t, sol.y[0], color=colors[i], alpha=0.5, linewidth=1)
    ax1.plot(sol.t, sol.y[1], color=colors[i], linestyle='--', alpha=0.5, linewidth=1)

    # 相图 (子图2)
    ax2.plot(sol.y[0], sol.y[1], color=colors[i], linewidth=1.5,
             label=f'({x0},{y0})')

ax1.set_xlabel('时间 t'); ax1.set_ylabel('种群数量')
ax1.set_title('Lotka-Volterra 时间序列')
ax1.legend(['猎物 (prey)', '捕食者 (predator)'], loc='upper right')

# 标注平衡点
x_eq = c / d  # = 25
y_eq = a / b  # = 10
ax2.plot(x_eq, y_eq, 'k*', markersize=12, label=f'平衡点 ({x_eq:.0f},{y_eq:.0f})')
ax2.set_xlabel('猎物 x'); ax2.set_ylabel('捕食者 y')
ax2.set_title('相图 (Phase Portrait)')
ax2.legend(); ax2.grid(True, alpha=0.3)

plt.tight_layout()
plt.savefig('output/lotka_volterra_full.png', dpi=300)

# 守恒量验证: V = d*x - c*ln(x) + b*y - a*ln(y) 是常数
print("守恒量 V 验证:")
for x0, y0 in initial_conditions:
    sol = solve_ivp(lotka_volterra, [0, 50], [x0, y0],
                    args=(a, b, c, d), max_step=0.1)
    V = (d*sol.y[0] - c*np.log(sol.y[0]) +
         b*sol.y[1] - a*np.log(sol.y[1]))
    print(f"  V({x0},{y0}): max-min={V.max()-V.min():.4e}")
```

**守恒量**（Lotka-Volterra 特有的首次积分）：
```
V(x, y) = d*x - c*ln(x) + b*y - a*ln(y)  = const.
```

这意味着相图是封闭轨道，振荡永不衰减 —— 这与现实不符（实际振荡通常是阻尼的）。

### 3.2 带密度制约的 Lotka-Volterra

更现实的版本：对猎物加入 Logistic 项。

```
dx/dt = a*x*(1 - x/K1) - b*x*y
dy/dt = d*x*y - c*y - e*y*(y/K2)      (可选项：捕食者种内竞争)
```

这个系统的相图是**稳定螺旋点** → 振荡衰减到平衡点。

```python
"""
用途: 带密度制约的 Lotka-Volterra（更现实）
特征: 猎物有环境容量 K，振荡最终衰减到平衡点
"""
import numpy as np
from scipy.integrate import solve_ivp
import matplotlib.pyplot as plt

def lv_density(t, z, a, b, c, d, K):
    x, y = z
    dx = a * x * (1 - x / K) - b * x * y
    dy = d * x * y - c * y
    return [dx, dy]

a, b, c, d = 1.0, 0.1, 0.5, 0.02
K = 80  # 猎物环境容量

sol = solve_ivp(lv_density, [0, 200], [40, 9],
                args=(a, b, c, d, K), max_step=0.2, dense_output=True)
t_fine = np.linspace(0, 200, 1000)
x_fine, y_fine = sol.sol(t_fine)

fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(14, 5))
ax1.plot(t_fine, x_fine, 'g-', label='猎物', linewidth=1.5)
ax1.plot(t_fine, y_fine, 'r-', label='捕食者', linewidth=1.5)
ax1.set_xlabel('时间'); ax1.set_ylabel('种群')
ax1.set_title('带密度制约 (Logistic prey)')
ax1.legend(); ax1.grid(True, alpha=0.3)

ax2.plot(x_fine, y_fine, 'b-', linewidth=1.5)
# 平衡点
x_eq = c / d
y_eq = a * (1 - x_eq / K) / b
ax2.plot(x_eq, y_eq, 'r*', markersize=12,
         label=f'稳定螺旋点 ({x_eq:.1f},{y_eq:.2f})')
ax2.set_xlabel('猎物 x'); ax2.set_ylabel('捕食者 y')
ax2.set_title('相图 — 振荡衰减到平衡点')
ax2.legend(); ax2.grid(True, alpha=0.3)
plt.tight_layout()
plt.savefig('output/lv_density_dependent.png', dpi=300)
```

**数模应用**：
- 加拿大林猞猁-雪兔周期（经典案例，有 100 年毛皮交易数据）
- 农业害虫-天敌释放策略
- 渔业管理中捕捞对生态系统的影响

## 四、传染病模型

### 4.1 SIR 模型

**基本假设**：
- 总人口 N = S + I + R (易感 Susceptible + 感染 Infectious + 康复 Recovered)
- 康复后获得终生免疫（不再感染）
- 混合均匀假设（mass action）

**微分方程组**：
```
dS/dt = -beta * S * I / N
dI/dt =  beta * S * I / N - gamma * I
dR/dt =  gamma * I
```

**关键参数**：
- `beta`: 有效接触率（每个感染者每天传染人数）
- `gamma`: 康复率（1/gamma 为平均传染期）
- `R0 = beta / gamma`: 基本再生数

**平衡点**：
- 无病平衡点 (DFE): (S, I, R) = (N, 0, 0)
- 地方病平衡点 (EE): (S*, I*, R*) = (N/R0, N*(1-1/R0), ...)
  - R0 > 1 时 EE 才存在

```python
"""
用途: SIR 传染病模型 — 基础版
输入: N, beta, gamma, I0; 输出: S(t), I(t), R(t)
核心: 演示 R0 对疫情走势的影响
"""
import numpy as np
from scipy.integrate import solve_ivp
import matplotlib.pyplot as plt

def sir(t, y, N, beta, gamma):
    S, I, R = y
    dS = -beta * S * I / N
    dI =  beta * S * I / N - gamma * I
    dR =  gamma * I
    return [dS, dI, dR]

# 参数
N = 10000          # 总人口
beta = 0.35        # 有效接触率 (天^-1)
gamma = 0.1        # 康复率 (天^-1)
R0 = beta / gamma  # 基本再生数
print(f"R0 = {R0:.2f}")

I0 = 5; R0_init = 0; S0 = N - I0 - R0_init

sol = solve_ivp(sir, [0, 200], [S0, I0, R0_init],
                args=(N, beta, gamma), max_step=0.5, dense_output=True)

t_fine = np.linspace(0, 200, 500)
S_fine, I_fine, R_fine = sol.sol(t_fine)

plt.figure(figsize=(12, 5))
plt.plot(t_fine, S_fine, 'b-', linewidth=2, label='S 易感者')
plt.plot(t_fine, I_fine, 'r-', linewidth=2, label='I 感染者')
plt.plot(t_fine, R_fine, 'g-', linewidth=2, label='R 康复者')
plt.axvline(x=np.argmax(I_fine), color='gray', linestyle=':',
            label=f'感染峰值日: {np.argmax(I_fine)}', alpha=0.7)
plt.xlabel('时间 (天)'); plt.ylabel('人数')
plt.title(f'SIR 模型 (R0 = {R0:.2f}, beta={beta}, gamma={gamma})')
plt.legend(); plt.grid(True, alpha=0.3)
plt.savefig('output/sir_basic.png', dpi=300)

print(f"最终感染人数: {R_fine[-1]:.0f} ({R_fine[-1]/N*100:.1f}%)")
print(f"峰值感染人数: {I_fine.max():.0f} (第 {np.argmax(I_fine)} 天)")
```

### 4.2 R0 的计算与解读

**R0 (基本再生数)** 是传染病模型最重要的指标：

| 定义 | 一个感染者在完全易感人群中平均感染的人数 |
|:----:|:----------------------------------------|
| R0 < 1 | 疾病自然消亡 |
| R0 = 1 | 地方病稳定 (endemic) |
| R0 > 1 | 疾病爆发流行 |

**常见传染病的 R0 估计**：

| 疾病 | R0 | 传染期 (天) | beta = R0 * gamma |
|:----:|:--:|:----------:|:-----------------:|
| 季节性流感 | 1.2 - 1.8 | 5-7 | ~0.25 |
| 新冠 (原始株) | 2.5 - 3.5 | 10-14 | ~0.25 |
| 新冠 (Omicron) | 8 - 12 | 7-10 | ~1.0 |
| 天花 | 5 - 7 | 20-25 | ~0.3 |
| 麻疹 | 12 - 18 | 10-14 | ~1.2 |

**从 SIR 模型反推 R0**（参数拟合思路）：
```
R0 = beta / gamma
gamma ≈ 1 / 平均传染期       (可从临床数据获得)
beta ≈ 初始增长阶段的增长率    (从疫情早期病例数据拟合)
```

**群体免疫阈值**：`h = 1 - 1/R0`
- 即需要接种疫苗的人口比例
- R0 = 3 时，h ≈ 66.7%；R0 = 10 时，h ≈ 90%

```python
"""
用途: 计算并可视化 R0 的影响 — 多情景对比
"""
import numpy as np
from scipy.integrate import solve_ivp
import matplotlib.pyplot as plt

def run_sir(beta, gamma, N=10000, I0=5, days=200):
    """辅助函数：运行一次 SIR 并返回结果"""
    def sir(t, y):
        S, I, R = y
        dS = -beta * S * I / N
        dI = beta * S * I / N - gamma * I
        dR = gamma * I
        return [dS, dI, dR]
    S0 = N - I0
    sol = solve_ivp(sir, [0, days], [S0, I0, 0], max_step=0.5)
    return sol

# 不同 R0 情景 (固定 gamma, 改变 beta)
gamma = 0.1
R0_list = [0.8, 1.5, 3.0, 5.0]
colors = ['green', 'blue', 'orange', 'red']

plt.figure(figsize=(12, 6))
for R0_val, color in zip(R0_list, colors):
    beta = R0_val * gamma
    sol = run_sir(beta, gamma)
    plt.plot(sol.t, sol.y[1], color=color, linewidth=1.5,
             label=f'R0={R0_val:.1f} (beta={beta:.2f})')
    # 标注峰值
    peak_idx = np.argmax(sol.y[1])
    plt.plot(sol.t[peak_idx], sol.y[1, peak_idx], 'o', color=color, markersize=6)

plt.xlabel('时间 (天)'); plt.ylabel('感染者 I(t)')
plt.title('不同 R0 对疫情走势的影响 (gamma=0.1 固定)')
plt.legend(); plt.grid(True, alpha=0.3)
plt.savefig('output/r0_comparison.png', dpi=300)

# 计算群体免疫阈值
print("R0 → 群体免疫阈值 h")
for R0_val in R0_list:
    if R0_val > 1:
        h = 1 - 1/R0_val
        print(f"  R0={R0_val:.1f} → h={h*100:.1f}%")
```

### 4.3 SIRS 模型（有免疫丧失）

**改进**：康复者在一段时间后重新变为易感者（免疫不持久）。

```
dS/dt = -beta * S * I / N + zeta * R
dI/dt =  beta * S * I / N - gamma * I
dR/dt =  gamma * I - zeta * R
```

其中 `zeta` 为免疫丧失率，`1/zeta` 为平均免疫持续时间。

**SIRS 的关键特征**：当 zeta > 0 时，疾病成为**地方病**（持续存在）。

```python
"""
用途: SIRS 模型 — 有免疫丧失的传染病模型
对比: SIR vs SIRS (免疫丧失导致疾病持续存在)
"""
import numpy as np
from scipy.integrate import solve_ivp
import matplotlib.pyplot as plt

def sirs(t, y, N, beta, gamma, zeta):
    S, I, R = y
    dS = -beta * S * I / N + zeta * R
    dI =  beta * S * I / N - gamma * I
    dR =  gamma * I - zeta * R
    return [dS, dI, dR]

N, beta, gamma = 10000, 0.35, 0.1
zeta = 0.02  # 免疫丧失率 (平均免疫 50 天)
R0 = beta / gamma

I0 = 5; S0 = N - I0; R0_val = 0

sol_sir = solve_ivp(
    lambda t, y: [ -beta*y[0]*y[1]/N,
                    beta*y[0]*y[1]/N - gamma*y[1],
                    gamma*y[1] ],
    [0, 500], [S0, I0, 0], max_step=0.5)

sol_sirs = solve_ivp(sirs, [0, 500], [S0, I0, R0_val],
                     args=(N, beta, gamma, zeta), max_step=0.5)

fig, (ax1, ax2) = plt.subplots(2, 1, figsize=(12, 8))

ax1.plot(sol_sir.t, sol_sir.y[0], 'b-', label='S')
```

### 4.4 模型扩展家族

```
SIR  →  SEIR   (加入潜伏期 Exposed)
     →  SIRS   (免疫丧失)
     →  SIERD  (加入死亡)
     →  SIR-V  (加入疫苗接种)
     →  SEIHR  (加入住院/隔离)
     →  metapopulation  (多区域耦合)
```

**SEIR 模型**（国赛高频）：
```
dS/dt = -beta * S * I / N
dE/dt =  beta * S * I / N - sigma * E     (E: 潜伏期, sigma: 潜伏→感染率)
dI/dt =  sigma * E - gamma * I
dR/dt =  gamma * I
```

## 五、稳定性分析与相平面

### 5.1 平衡点与稳定性分类

对于二维自治系统：
```
dx/dt = f(x, y)
dy/dt = g(x, y)
```

在平衡点 (x*, y*) 处计算 Jacobian 矩阵：
```
J = [[df/dx, df/dy],
     [dg/dx, dg/dy]]
```

特征值 λ1, λ2 决定稳定性：

| 特征值 | 类型 | 稳定性 |
|:------:|:----:|:------:|
| 两个负实根 | 稳定结点 (stable node) | 稳定 |
| 两个正实根 | 不稳定结点 (unstable node) | 不稳定 |
| 一正一负 | 鞍点 (saddle) | 不稳定 |
| 负实部共轭复根 | 稳定螺旋点 (stable spiral) | 稳定 |
| 正实部共轭复根 | 不稳定螺旋点 (unstable spiral) | 不稳定 |
| 纯虚根 | 中心 (center) | 临界稳定 |

### 5.2 向量场与相平面绘制

```python
"""
用途: 相平面 — 向量场 + 多条轨线 + 平衡点标注
模型: Logistic + Lotka-Volterra 混合
"""
import numpy as np
import matplotlib.pyplot as plt

def plot_phase_portrait(f, g, x_range, y_range, grid=20, trajectories=None):
    """
    绘制二维自治系统的相平面
    参数:
        f, g: dx/dt=f(x,y), dy/dt=g(x,y)
        x_range, y_range: [min, max]
        trajectories: 轨线初值列表 [(x0,y0), ...]
    """
    x = np.linspace(*x_range, grid)
    y = np.linspace(*y_range, grid)
    X, Y = np.meshgrid(x, y)

    # 计算向量场
    U = f(X, Y)
    V = g(X, Y)

    # 归一化箭头长度
    M = np.sqrt(U**2 + V**2)
    U_norm = U / (M + 1e-8)
    V_norm = V / (M + 1e-8)

    plt.figure(figsize=(9, 8))
    plt.quiver(X, Y, U_norm, V_norm, M, alpha=0.4, cmap='viridis')
    plt.colorbar(label='|dX/dt| 速率')

    # 绘制轨线
    if trajectories:
        from scipy.integrate import solve_ivp
        for x0, y0 in trajectories:
            def ode(t, z):
                return [f(z[0], z[1]), g(z[0], z[1])]
            sol = solve_ivp(ode, [0, 50], [x0, y0], max_step=0.05)
            plt.plot(sol.y[0], sol.y[1], 'b-', linewidth=1.5, alpha=0.7)

    plt.xlabel('x'); plt.ylabel('y')
    plt.title('相平面分析 (Phase Portrait)')
    plt.grid(True, alpha=0.3)
    plt.xlim(x_range); plt.ylim(y_range)
    plt.savefig('output/phase_portrait.png', dpi=300)

# ====== 示例：Logistic + 捕食 ======
# dx/dt = x*(1-x/100) - 0.02*x*y
# dy/dt = 0.01*x*y - 0.3*y

def f(x, y):
    return x * (1 - x/100) - 0.02 * x * y

def g(x, y):
    return 0.01 * x * y - 0.3 * y

# 平衡点计算
# P1: (0,0), P2: (100,0), P3: (30, 70/0.02=35)
print("平衡点:")
print(f"  P1 (0, 0)")
print(f"  P2 (100, 0)")
print(f"  P3 (30, 35)")

plot_phase_portrait(f, g, [0, 120], [0, 60],
                    grid=18,
                    trajectories=[(10, 5), (20, 30), (50, 20), (80, 10)])
```

### 5.3 传染病模型的相平面分析

对于 SIR 模型，由于 S + I + R = N，只需关注 S-I 平面。

```
dI/dS = (beta*S*I/N - gamma*I) / (-beta*S*I/N)
      = -1 + 1/(R0*(S/N))
```

```python
"""
用途: SIR 模型在 S-I 相平面上的轨线
"""
import numpy as np
import matplotlib.pyplot as plt
from scipy.integrate import solve_ivp

def sir_phase(beta, gamma, N=10000):
    """绘制 SIR 在 S-I 平面的轨线族"""
    fig, ax = plt.subplots(1, 1, figsize=(8, 6))

    R0 = beta / gamma
    S_threshold = N / R0  # 阈值 S* = N/R0

    # 在不同 (S0, I0) 初值下绘制轨线
    init_conds = []
    for S0_pct in [0.99, 0.95, 0.85, 0.70]:
        S0 = N * S0_pct
        init_conds.append((S0, 5))
    init_conds.extend([(N*0.99, 50), (N*0.9, 200)])

    colors = plt.cm.viridis(np.linspace(0.2, 0.9, len(init_conds)))

    for i, (S0, I0) in enumerate(init_conds):
        def sir(t, y):
            S, I = y
            dS = -beta * S * I / N
            dI = beta * S * I / N - gamma * I
            return [dS, dI]
        sol = solve_ivp(sir, [0, 300], [S0, I0], max_step=0.5)
        ax.plot(sol.y[0], sol.y[1], color=colors[i], linewidth=1.5,
                label=f'S0={S0:.0f}, I0={I0:.0f}')
        # 标记终点
        ax.plot(sol.y[0, -1], sol.y[1, -1], 'o', color=colors[i], markersize=5)

    # 标注阈值
    ax.axvline(S_threshold, color='red', linestyle='--', linewidth=1.5,
               label=f'S* = N/R0 = {S_threshold:.0f}')
    ax.set_xlabel('S (易感者)'); ax.set_ylabel('I (感染者)')
    ax.set_title(f'SIR 相平面 (R0={R0:.2f}) — I 仅当 S > S* 时上升')
    ax.legend(fontsize=8); ax.grid(True, alpha=0.3)
    plt.tight_layout()
    plt.savefig('output/sir_phase_plane.png', dpi=300)

sir_phase(beta=0.35, gamma=0.1)
```

**SIR 相平面的核心结论**：
1. 若 S0 < N/R0 → I 单调下降（不会爆发）
2. 若 S0 > N/R0 → 先爆发后衰减
3. 最终感染人数 = 所有"穿越"到 I=0 时的 S 的减少量

## 六、数模应用案例

### 案例 1：新冠疫情初期 — 参数估计与政策效果评估

**场景**：2020 年初，武汉疫情。需估计 R0、评估封城效果。

**建模思路**：
```
① 用 SEIR 模型 (加入潜伏期 E：平均 5.2 天)
② 拟合早期病例数 → 估计 beta → R0 = beta/gamma
③ 封城 → beta 显著降低 → 观察 R0 是否降到 1 以下
④ 若 R0 < 1 → 疫情得到控制
```

**关键结果（文献数据）**：
- 初始 R0 ≈ 2.2-3.5
- 封城后 R0 ≈ 0.3-0.5
- 验证了非药物干预 (NPIs) 的效果

### 案例 2：渔业资源管理 — Logistic 模型的直接应用

**场景**：某渔场最大可持续捕捞量。

**建模**：
```
dN/dt = r*N*(1 - N/K) - H*N         (H 为捕捞强度)
```

**最大可持续产量 (MSY)**：在 N = K/2 时，`dN/dt = r*K/4`，所以 MSY = r*K/4。

**管理策略**：控制捕捞强度 H < r*(1 - N/K)，否则种群崩溃。

### 案例 3：疫苗策略优化 — R0 的应用

**场景**：某传染病 R0=4，需接种多少人口才能消除？

**计算**：
```
群体免疫阈值 h = 1 - 1/R0 = 1 - 1/4 = 75%
→ 至少需要 75% 人口接种有效疫苗
```

**现实考量**：
- 疫苗有效率 < 100% → 需更高覆盖率
- 人口流动、异质性 → 需更精细的 metapopulation 模型

## 八、编程手速查模板

### 通用模板：任意种群/传染病 ODE 模型

```python
"""
用途: 生物种群/传染病模型 — 通用求解模板
输入: 修改下面 rhs(t, y, *params) 即可适配任何模型
输出: 时间序列图 + 相图 (2D 系统可选)
"""
import numpy as np
from scipy.integrate import solve_ivp
import matplotlib.pyplot as plt

# ====================== 用户修改区 ======================
# 1. 定义右端函数
def rhs(t, y, *params):
    """
    微分方程右端函数
    y 是状态向量, params 是模型参数元组
    返回 dy/dt 列表
    """
    # 示例：Logistic 模型
    # N = y[0]
    # r, K = params
    # return [r * N * (1 - N / K)]

    # 示例：Lotka-Volterra
    x, y = y
    a, b, c, d = params
    dx = a * x - b * x * y
    dy = d * x * y - c * y
    return [dx, dy]

# 2. 设置参数
params = (1.0, 0.1, 0.5, 0.02)   # 模型参数元组
y0 = [40.0, 9.0]                 # 初值
t_span = [0, 100]                # 时间区间

# 3. 求解选项
method = 'RK45'                 # RK45(默认) / BDF(刚性) / LSODA(自动检测)
max_step = 0.1                  # 最大步长（精度控制）
dense_output = True             # 是否插值（画平滑曲线用）
# ========================================================

# 求解
sol = solve_ivp(rhs, t_span, y0, args=params,
                method=method, max_step=max_step,
                dense_output=dense_output)

# 画时间序列图
t_fine = np.linspace(t_span[0], t_span[1], 500)
y_fine = sol.sol(t_fine)

n_vars = len(y0)
fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(14, 5)) if n_vars >= 2 else \
                  plt.subplots(1, 1, figsize=(10, 5))

# 子图 1: 时间序列
if n_vars >= 2:
    for i in range(n_vars):
        ax1.plot(t_fine, y_fine[i], linewidth=1.5, label=f'y{i+1}')
    ax1.set_xlabel('时间 t'); ax1.set_ylabel('状态变量')
    ax1.legend(); ax1.grid(True, alpha=0.3)
    # 子图 2: 相图
    ax2.plot(y_fine[0], y_fine[1], 'b-', linewidth=1.5)
    ax2.set_xlabel('y1'); ax2.set_ylabel('y2')
    ax2.set_title('相图 (Phase Portrait)')
    ax2.grid(True, alpha=0.3)
else:
    ax1 = fig.gca()
    ax1.plot(t_fine, y_fine[0], 'b-', linewidth=1.5)
    ax1.set_xlabel('时间 t'); ax1.set_ylabel('N(t)')
    ax1.grid(True, alpha=0.3)

plt.suptitle('生物种群/传染病模型数值解', fontsize=14)
plt.tight_layout()
plt.savefig('output/population_model.png', dpi=300)

# 打印关键结果
print("=== 模型结果摘要 ===")
print(f"时间范围: {t_span[0]} ~ {t_span[1]}")
print(f"最终状态: {sol.y[:, -1]}")
if n_vars >= 2:
    print(f"y1 峰值: {y_fine[0].max():.2f} @ t={t_fine[y_fine[0].argmax()]:.1f}")
    print(f"y2 峰值: {y_fine[1].max():.2f} @ t={t_fine[y_fine[1].argmax()]:.1f}")
```

```python
"""
```

### 参数拟合最小模板（从数据估 beta, gamma）

```python
"""
用途: 从早期病例数拟合 SIR 参数 beta, gamma
方法: 最小二乘 + scipy.optimize.curve_fit
注意: 数据量少时用 SIR 的早期近似 I(t) ~ I0*exp((R0-1)*gamma*t)
"""
import numpy as np
from scipy.optimize import curve_fit
import matplotlib.pyplot as plt

# 模拟"真实"数据 (实际使用时替换为真实数据)
t_data = np.array([0, 1, 2, 3, 4, 5, 6, 7])
I_data = np.array([5, 8, 14, 23, 38, 60, 95, 150])

# 早期近似: I(t) ≈ I0 * exp(lambda*t), 其中 lambda = gamma*(R0-1)
def exponential_growth(t, I0, lam):
    return I0 * np.exp(lam * t)

popt, pcov = curve_fit(exponential_growth, t_data, I_data,
                        p0=[5, 0.3])
I0_fit, lam_fit = popt

# 假设 gamma (可以根据临床数据设定)
gamma_est = 0.1           # 平均传染期 10 天
R0_est = 1 + lam_fit / gamma_est
beta_est = R0_est * gamma_est

print(f"拟合结果:")
print(f"  I0 = {I0_fit:.2f}")
print(f"  早期增长率 lambda = {lam_fit:.3f}")
print(f"  gamma (给定) = {gamma_est}")
print(f"  R0 (估计) = {R0_est:.2f}")
print(f"  beta (估计) = {beta_est:.3f}")

plt.figure(figsize=(8, 5))
plt.plot(t_data, I_data, 'ro', label='观测数据')
t_smooth = np.linspace(0, 7, 100)
plt.plot(t_smooth, exponential_growth(t_smooth, I0_fit, lam_fit),
         'b-', linewidth=2, label=f'拟合: I0={I0_fit:.2f}, lambda={lam_fit:.3f}')
plt.xlabel('时间 (天)'); plt.ylabel('感染者 I(t)')
plt.title('早期指数增长拟合 → 估计 R0')
plt.legend(); plt.grid(True, alpha=0.3)
plt.savefig('output/r0_fitting.png', dpi=300)
```

## 九、常用模型参数速查

| 模型 | 变量 | 典型参数范围 | 国赛常见考点 |
|:----:|:----:|:------------:|:------------:|
| **Logistic** | N | r: 0.01~1.0, K: 10^3~10^9 | 人口预测、资源承载力 |
| **Lotka-Volterra** | x, y | a: 0.5~2, b: 0.01~0.2, c: 0.2~1, d: 0.01~0.1 | 生态平衡、害虫防治 |
| **SIR** | S, I, R | beta: 0.1~1.0, gamma: 0.05~0.5 | 疫情预测、隔离效果 |
| **SIRS** | S, I, R | zeta: 0.005~0.05 | 免疫丧失、反复感染 |
| **SEIR** | S, E, I, R | sigma: 0.1~0.5 (1/潜伏期) | 新冠、流感建模 |

---

> **生物种群模型是国赛微分方程类的高频考点**。核心能力：① 根据问题背景选对模型结构（SIR vs SIRS vs SEIR）；② 从数据估计参数（最小二乘拟合 beta, gamma）；③ 用 R0 定量评估干预策略效果；④ 用相图分析系统长期行为。比赛时直接套用"编程手速查模板"，改右端函数和参数即可快速出结果。
