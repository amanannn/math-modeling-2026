## 一、2017 A 题回顾

### 题目：CT 系统参数标定及成像

**已知**：
1. 一个方形托盘上放置两个均匀固体介质（位置已知）
2. 一束 X 射线旋转扫描，180 个方向下的接收信息（`附件1.xlsx`）
3. 另一组未知样品的投影数据（`附件2.xlsx`）

**要求**：
1. 根据模板的已知几何结构，**标定 CT 系统的参数**（旋转中心、探测器单元间距、180 个方向的角度）
2. 用标定好的参数，**重建未知样品的图像**——给出吸收率、位置、几何形状
3. 分析精度与稳定性

## 二、拿到题目，先问什么？

### 2.1 第一步：问题理解（不要急着建模！）

```
我要做什么？
├── 数据长什么样？
│   └── 180行 × 512列的矩阵 → 180 个角度，512 个探测器单元
│   └── 每个数值 = 经过物体衰减后的射线强度
│
├── CT 的物理是什么？
│   └── X 射线穿过物体 → 指数衰减: I = I0·exp(-∫ μ dl)
│   └── 测量值 = ln(I0/I) = ∫ μ dl = 投影 (Radon 变换)
│   └── 已知所有角度的投影 → 反求物体内部 μ(x,y) → 重建图像
│
└── 需要求什么？
    ├── 问题1：系统参数（几何）→ 已知物体形状，反推几何
    └── 问题2：重建图像      → 已知几何+投影，反推物体
```

### 2.2 第二步：识别问题类型

```
问题1 = 参数估计问题（已知模型结构+输入+输出，反推模型参数）
问题2 = 逆问题（已知正变换的投影数据，反求原函数）
```

### 2.3 第三步：建立数学框架

**核心方程 — Radon 变换**：

```
投影 p(s, θ) = ∫ μ(r) · δ(r·n_θ - s) dr

其中：
  μ(x,y) — 物体内部衰减系数分布（要重建的）
  n_θ = (cosθ, sinθ) — 射线方向
  s — 射线到旋转中心的距离（探测器位置）
  δ — Dirac 函数（只沿射线积分）
```

**离散化**：这就是线性方程组 `Ax = b`

- `x` — 物体衰减系数的离散化（N² 个像素值）
- `b` — 所有投影数据（180 × 512 个测量值）
- `A` — 投影矩阵/系统矩阵（几何关系决定的稀疏矩阵）

## 三、核心假设的提出与论证

> 数模最关键的步骤：**假设 = 把复杂现实问题变成可求解的数学问题**

### 3.1 第一层假设：物理层

| 假设 | 内容 | 合理性论证 |
|------|------|-----------|
| **单能X射线** | X 光源是单能的（无能谱展宽） | 标定模板材料均匀，能谱效应在均匀介质中可忽略 |
| **忽略散射** | 探测器只接收直射光子，忽略康普顿散射 | 窄束准直条件，散射贡献 < 5% |
| **线积分模型** | 探测器每个单元接收对应一条理想直线的积分 | 探测器尺寸远小于物体尺寸，可近似为点 |
| **Beer-Lambert 定律** | I = I0·exp(-∫μ dl)，介质均匀时严格成立 | 这是 CT 的物理基础 |

### 3.2 第二层假设：几何层

| 假设 | 内容 | 论证 |
|------|------|------|
| **平行束** | 射线是平行线（非扇形束） | 题目描述的"一束射线"和 512 个等距探测单元暗示平行束 |
| **等角间距** | 180 个投影方向等间隔分布 | 典型 CT 扫描模式 |
| **刚性旋转** | 旋转过程中模板位置稳定 | 忽略机械误差（精度分析阶段再讨论） |

### 3.3 第三层假设：计算层

| 假设 | 内容 | 论证 |
|------|------|------|
| **离散化网格** | 物体用 N×N 像素网格表示 | 标准 CT 重建方法 |
| **射线宽度为零** | 每条射线积分路径是无限细的线 | 先忽略探测器宽度导致的卷积分效应 |
| **均匀背景** | 空气的衰减系数为 0 | 对 μ 做相对测量 |

### 3.4 假设的"好"与"坏"标准

```
好假设：
是 能显著简化问题（如忽略散射  → 从辐射传输简化为线积分）
是 有物理/工程依据（引用文献或给估算）
是 可后续验证（精度分析阶段用更复杂模型验证偏差）

坏假设：
否 为了简化而简化，没有依据（如"忽略噪声"——噪声在 CT 中至关重要）
否 假设自相矛盾（如假设平行束却用扇形束重建算法）
否 假设过多导致模型与实际偏差太大
```

## 四、建模思路的演进

### 问题 1：参数标定

```
思考路径：

最初想法：每个角度下的投影数据都包含模板的投影信息
    ↓
关键洞察：模板是两个圆，其**投影轮廓**与角度有关
    ↓
建模：圆的投影宽度 = f(圆的直径, 探测器间距, 旋转中心偏移)
    ↓
已知：圆的真实直径 → 可反推探测器和几何参数
    ↓
方法：非线性最小二乘拟合
```

**具体思路**：

```
1. 从投影数据中提取模板边缘（阈值法 → 边界位置）

2. 每个角度下，模板两个圆的投影中心位置可测

3. 设未知参数：
   θ = [探测器间距 d, 旋转中心偏移 Δs, 起始角度 θ0, 角度增量 Δθ]

4. 理论投影中心位置 = f(圆真实位置, θ)
   实测投影中心位置 = g(投影数据)

5. 最小化: Σ|理论 - 实测|2 → 得到 θ 的最优估计
```

### 问题 2：图像重建

```
思考路径：

方案A：直接反投影（Back Projection）
  → 简单但图像模糊，需要滤波

方案B：滤波反投影 (FBP, Filtered Back Projection)
  → CT 工业标准，速度快，需要问题1的参数

方案C：迭代重建 (ART/SART)
  → 可以处理噪声、不完全采样，计算量大

选型决策：
  本题投影数据完整（180°全覆盖）、噪声低
  → FBP 最优
  → 但如果想展示创新，可用 SART 作为补充对比
```

**FBP 核心公式**：

```
μ(x,y) = ∫₀^π [p(s,θ) * h(s)] dθ

其中：
  * 代表卷积
  h(s) — 斜坡滤波器 (Ram-Lak filter)
  p(s,θ) — 投影数据
```

**重建流程**：

```
投影数据 p(s,θ)
    ↓
① 对每个角度，对投影做 FFT
    ↓
② 频域乘以斜坡滤波器 |ω| — 高频增强，消除模糊
    ↓
③ IFFT 回到空域 → 滤波后的投影
    ↓
④ 反投影：将每个角度的滤波投影"涂抹"回图像空间
    ↓
⑤ 图像 μ(x,y)
```

## 五、方法选择对比

### 问题 1：参数标定方法

| 方法 | 优点 | 缺点 | 选择 |
|------|------|------|:----:|
| 解析几何法 | 推导清晰，有显式公式 | 对噪声敏感，容错性差 | |
| 最小二乘拟合 | 利用所有数据，鲁棒 | 需要初始值 | **首选** 是 |
| Hough 变换 | 自动提取直线/正弦图 | 计算量大 | 辅助 |
| 互相关匹配 | 精度高 | 计算量大 | 可选 |

### 问题 2：图像重建方法

| 方法 | 精度 | 速度 | 抗噪 | 是否选 |
|------|:----:|:----:|:----:|:------:|
| 直接反投影 | 低 | 快 | 差 | 否 太模糊 |
| **FBP (滤波反投影)** | 高 | 快 | 中 | **首选** 是 |
| ART (迭代) | 中 | 慢 | 好 | 作为对比 是 |
| SART (同时迭代) | 高 | 中 | 好 | 作为对比 |
| 压缩感知 (CS) | 最高 | 慢 | 最强 | 降采样时才用 |
| 深度学习 (CNN) | 高 | 快(推理) | 好 | 否 本题不需要 |

**推荐方案：FBP 为主 + SART 为辅**
- FBP 给出基准结果（生产级、有理论保证）
- SART 展示对噪声/伪影的处理能力（论文创新点）
- 两者对比 → 论文讨论部分的核心内容

### 6.2 FBP 图像重建（Radon 变换反演）

```python
"""
用途: FBP 滤波反投影重建 CT 图像
输入: 投影数据 (angles × detectors), 探测器间距, 角度列表
输出: 重建图像 μ(x,y)
"""
import numpy as np
from scipy.fft import fft, ifft, fftshift
import matplotlib.pyplot as plt

def fbp_reconstruct(sinogram, angles_rad, detector_spacing, n_pixels):
    """
    FBP 重建
    sinogram: 投影数据 (n_angles × n_detectors)
    angles_rad: 角度列表（弧度）
    detector_spacing: 探测器间距
    n_pixels: 重建图像的像素数
    """
    n_angles, n_detectors = sinogram.shape

    # ===== 步骤1: 频域滤波 =====
    # 构建斜坡滤波器 (Ram-Lak)
    freqs = np.fft.fftfreq(n_detectors, d=detector_spacing)
    ramp = np.abs(freqs)
    ramp = fftshift(ramp)

    # 对每个角度的投影做 FFT → 乘斜坡滤波器 → IFFT
    filtered_sino = np.zeros_like(sinogram)
    for i in range(n_angles):
        proj_fft = fft(sinogram[i, :])
        filtered_sino[i, :] = np.real(ifft(proj_fft * ramp))

    # ===== 步骤2: 反投影 =====
    img = np.zeros((n_pixels, n_pixels))
    center = n_pixels / 2
    x = np.arange(n_pixels) - center
    X, Y = np.meshgrid(x, x)

    for i in range(n_angles):
        theta = angles_rad[i]
        # 计算每个像素在该角度下对应的探测器位置
        s = X * np.cos(theta) + Y * np.sin(theta)
        # 线性插值获取滤波后的投影值
        s_idx = s / detector_spacing + n_detectors / 2
        s_idx = np.clip(s_idx, 0, n_detectors - 1)
        s0 = np.floor(s_idx).astype(int)
        s1 = np.minimum(s0 + 1, n_detectors - 1)
        frac = s_idx - s0
        # 双线性插值
        interp = (1 - frac) * filtered_sino[i, s0] + frac * filtered_sino[i, s1]
        img += interp

    # 归一化
    img *= np.pi / n_angles
    return img
```

```python
"""
用途: CT几何参数标定 — 非线性最小二乘
核心思想: 利用模板圆投影轨迹反推几何参数
"""
from scipy.optimize import least_squares
import numpy as np

def projection_model(params, true_circle_positions, n_angles):
    """
    前向模型：给定几何参数 → 预测每个角度下圆的投影中心
    params = [detector_spacing, center_offset, theta0, delta_theta]
    """
    d, offset, theta0, dtheta = params
    angles = theta0 + np.arange(n_angles) * dtheta
    predicted = []
    for cx, cy in true_circle_positions:  # 圆真实坐标
        for theta in angles:
            # 圆的投影中心 = 圆心到探测器平面的投影
            s = cx * np.cos(theta) + cy * np.sin(theta) + offset
            predicted.append(s)
    return np.array(predicted)

def residual(params, true_circle_positions, n_angles, measured_centers):
    """残差函数：理论值 - 实测值"""
    pred = projection_model(params, true_circle_positions, n_angles)
    return pred - measured_centers
```

## 七、从这道题学到的建模方法论

### 7.1 建模的核心工作流

```
问题理解（30%时间）→ 假设建立（20%）→ 模型构建（30%）→ 求解验证（20%）
       ↑                                                        ↓
       └──────── 不合格，迭代 ───────────────────────────────────┘
```

### 7.2 方法论提炼

| 阶段 | 关键动作 | 2017A 题的体现 |
|------|---------|---------------|
| **问题理解** | 查阅背景知识，理解数据的物理含义 | 查 CT 原理 → 发现投影 = Radon 变换 |
| **提出假设** | 简化现实，让问题可求解 | 平行束、单能X射线、忽略散射 |
| **分解问题** | 把大问题拆成小问题串行求解 | 问题1(标定) → 问题2(重建)，串联 |
| **方法选型** | 列候选方案，对比优劣，选最优 | FBP vs ART：4 维度对比后选 FBP |
| **数值实现** | 验证 → 调参 → 对比 → 优化 | 标定精度 → 影响重建质量 → 敏感度分析 |
| **结果分析** | 不只是"得出结果"，而是分析"为什么" | 边缘模糊原因？→ 探测器宽度/部分体积效应 |
| **论文包装** | 把技术细节转化为可读的叙述 | 正弦图 → 参数标定 → 重建图像 → 误差分析 |

### 7.3 常见的"坑"与规避

| 常见错误 | 正确做法 |
|----------|---------|
| 拿到数据就开始跑模型 | 先画图！先画正弦图，看数据长什么样 |
| 直接用 scikit-image 自带的 `iradon` | 理解 FBP 原理再调用，论文里能写出公式 |
| 忽略 Radon 变换的数学基础 | 逆问题的适定性 → 需要滤波 → 能解释为什么 FBP 用斜坡滤波 |
| 不分析假设的合理性 | 每个假设都要写"为什么可以这样简化和可能带来的误差" |
| 问题1 和问题2 割裂 | 问题1 的标定误差必然传递到问题2，做误差传播分析 |

## 八、通用建模启示

### 从 2017A 可以迁移到任何数模题的经验

```
① 物理建模 → 数学方程
   CT → Radon变换 + Beer定律
   热传导 → Fourier定律 + 热扩散方程
   流体 → Navier-Stokes（简化!）

② 逆问题思维
   已知结果反推原因 → 正则化是核心（Tikhonov, L1, TV）

③ 参数标定 → 再求解
   先由已知物体标定系统 → 再由系统反推未知物体
   这个"两步走"思路适用于所有测量/探测类问题

④ 从数据中提取特征
   正弦图中的正弦曲线 → 参数估计的约束条件
   不直接拟合全部数据，而是先提取关键特征再拟合

⑤ 多种方法对比 = 论文厚度
   FBP做基准 + SART做对比 → 论文讨论部分很充实
   不要只用一种方法
```

> **这篇笔记的核心**：建模不是套公式，是**问题理解 → 假设 → 分解 → 选型 → 实现 → 验证**的完整链条。2017 A 题完美展示了这个流程——物理原理 (Beer定律) → 数学框架 (Radon变换/逆问题) → 分解求解 (标定+重建) → 数值实现 (FBP/SART) → 结果分析 (误差传播)。遇到任何新题，先跑通这个思维链再动手写代码。
