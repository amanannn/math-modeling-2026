```
现实世界的"变化"问题
├── 随时间变化 → 常微分方程 (ODE)
│   ├── 人口增长、传染病传播
```

## 二、常微分方程 (ODE) 数值方法

### 2.1 标准形式

一阶 ODE 组的标准形式：

```
dy/dt = f(t, y)
y(t0) = y0        (初始条件)
```

**高阶 → 一阶的降阶技巧**：二阶 `d2x/dt2 = f(t, x, dx/dt)`，令 `v = dx/dt`：

```
dx/dt = v
dv/dt = f(t, x, v)
```

得到两个一阶方程，写成向量 `[x, v]`。

### 2.2 数值方法对比

| 方法 | 精度 | 稳定性 | 适用场景 |
|------|:----:|:------:|----------|
| **欧拉法 (Euler)** | O(h) | 差 | 教学理解，不推荐实际使用 |
| **改进欧拉 (Heun)** | O(h2) | 中 | 快速验证 |
| **经典 RK4** | O(h4) | 好 | **最常用，性价比最高** |
| **Dormand-Prince (RK45)** | O(h5) | 好  | **scipy 默认，推荐首选** |
| **BDF (向后差分)** | O(h1~h5) | 刚性 | **刚性方程专用** |

### 2.3 刚性方程 (Stiff ODE)

**特征**：方程组中各分量变化速率差异极大，比如同时有秒级和年级的过程。

**表现**：用 RK45 会无限缩小步长、卡死。

**对策**：换用专门求解器：

```python
# solve_ivp(method='Radau')  中低精度刚性问题
# solve_ivp(method='BDF')    一般刚性问题
# solve_ivp(method='LSODA')  自动检测是否为刚性并切换
```

## 三、Python 求解 ODE —— scipy.integrate

### 3.1 核心函数：solve_ivp

```python
"""
用途: scipy 求解 ODE 初值问题 — 通用模板
输入: 右端函数 f(t,y), 时间区间 [t0,tf], 初值 y0
输出: t 和 y 的数值解
"""
import numpy as np
from scipy.integrate import solve_ivp

# 定义ODE: dy/dt = f(t, y)
def f(t, y):
    return -2 * y  # dy/dt = -2y, 解析解: y = e^{-2t}

# 求解
sol = solve_ivp(f, t_span=[0, 3], y0=[1.0],
                method='RK45',        # 默认，可换 'BDF' 'Radau' 'LSODA'
                rtol=1e-6, atol=1e-9, # 相对/绝对误差容限
                dense_output=True)

# 获取任意点的值
t_fine = np.linspace(0, 3, 100)
y_fine = sol.sol(t_fine)  # dense_output 允许插值

# 与解析解对比
y_exact = np.exp(-2 * t_fine)
error = np.max(np.abs(y_fine[0] - y_exact))
print(f"最大误差: {error:.2e}")  # 输出: 最大误差: ~1e-7
```

### 3.2 高阶 ODE 案例 —— 阻尼振动

> 质量-弹簧-阻尼系统：mx'' + cx' + kx = 0

```python
"""
用途: 二阶ODE求解 — 阻尼振动
方程: x'' + 0.5x' + 5x = 0, x(0)=1, x'(0)=0
降阶: v = x' → x'=v, v'=-0.5v-5x
"""
import numpy as np
from scipy.integrate import solve_ivp
import matplotlib.pyplot as plt

def damped_oscillator(t, y):
    x, v = y
    return [v, -0.5 * v - 5 * x]

sol = solve_ivp(damped_oscillator, [0, 20], [1.0, 0.0],
                method='RK45', rtol=1e-8, atol=1e-10,
                max_step=0.1)

plt.figure(figsize=(10, 4))
plt.plot(sol.t, sol.y[0], 'b-', label='位移 x(t)', linewidth=1.5)
plt.plot(sol.t, sol.y[1], 'r--', label='速度 v(t)', linewidth=1.5)
plt.xlabel('时间 t'); plt.ylabel('x / v')
plt.title('阻尼振动数值解 (RK45)')
plt.legend(); plt.grid(True, alpha=0.3)
plt.savefig('output/damped_oscillator.png', dpi=300)
```

### 3.3 参数敏感度 —— solve_ivp 关键参数

| 参数 | 含义 | 建议值 |
|------|------|--------|
| `method` | 求解器 | 日常用 `RK45`，刚性用 `BDF` |
| `rtol` | 相对误差 | `1e-6`（默认，一般够用） |
| `atol` | 绝对误差 | `1e-9` |
| `max_step` | 最大步长 | 振荡问题设小些（如 `0.1`）防止跳过细节 |
| `dense_output` | 是否允许插值 | `True`（方便后处理画图） |
| `events` | 事件检测 | 当某个条件满足时停止（如撞地、到达终点） |

## 四、数模经典案例

### 4.1 传染病模型 (SIR)

```
S'(t) = -beta * S * I / N
I'(t) =  beta * S * I / N - gamma * I
R'(t) =  gamma * I
```

```python
"""
用途: SIR 传染病模型数值求解
输入: 总人口 N, 感染率 beta, 康复率 gamma, 初值 S0/I0/R0
输出: S(t), I(t), R(t) 曲线
"""
import numpy as np
from scipy.integrate import solve_ivp
import matplotlib.pyplot as plt

def sir(t, y, N, beta, gamma):
    S, I, R = y
    dS = -beta * S * I / N
    dI =  beta * S * I / N - gamma * I
    dR =  gamma * I
    return [dS, dI, dR]

N = 10000; beta = 0.3; gamma = 0.1
I0 = 10; R0 = 0; S0 = N - I0 - R0

sol = solve_ivp(sir, [0, 160], [S0, I0, R0],
                args=(N, beta, gamma), max_step=0.5)

plt.figure(figsize=(10, 5))
plt.plot(sol.t, sol.y[0], 'b-', label='S: 易感者')
plt.plot(sol.t, sol.y[1], 'r-', label='I: 感染者')
plt.plot(sol.t, sol.y[2], 'g-', label='R: 康复者')
plt.xlabel('时间 (天)'); plt.ylabel('人数')
plt.title(f'SIR 模型 (R0={beta/gamma:.1f})')
plt.legend(); plt.grid(True, alpha=0.3)
plt.savefig('output/sir_model.png', dpi=300)
```

### 4.2 捕食者-猎物模型 (Lotka-Volterra)

```
dx/dt = alpha * x - beta * x * y    (猎物)
dy/dt = delta * x * y - gamma * y   (捕食者)
```

```python
"""
用途: Lotka-Volterra 捕食者-猎物方程
演示: 周期振荡、相图分析
"""
import numpy as np
from scipy.integrate import solve_ivp
import matplotlib.pyplot as plt

def lotka_volterra(t, z, a, b, d, g):
    x, y = z
    return [a*x - b*x*y, d*x*y - g*y]

a, b, d, g = 1.0, 0.1, 0.02, 0.5  # 参数
sol = solve_ivp(lotka_volterra, [0, 100], [40, 9],
                args=(a, b, d, g), max_step=0.2)

fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(12, 4))
ax1.plot(sol.t, sol.y[0], 'g-', label='猎物')
ax1.plot(sol.t, sol.y[1], 'r-', label='捕食者')
ax1.set_xlabel('时间'); ax1.legend(); ax1.grid(True, alpha=0.3)

ax2.plot(sol.y[0], sol.y[1], 'b-')
ax2.set_xlabel('猎物 x'); ax2.set_ylabel('捕食者 y')
ax2.set_title('相图 (Phase Portrait)')
ax2.grid(True, alpha=0.3)
plt.savefig('output/lotka_volterra.png', dpi=300)
```

### 4.3 追击问题 (Pursuit Curve)

> A 以恒定速度从原点出发沿 y 轴跑，B 始终朝向 A 追击，B 的速度是 A 的 k 倍。求 B 的轨迹。

```python
"""
用途: 微分方程建模 — 追击曲线
特点: ODE 右端涉及时间变化的追击关系
"""
import numpy as np
from scipy.integrate import solve_ivp
import matplotlib.pyplot as plt

def pursuit(t, y, va, vb):
    """y = [xa, ya, xb, yb] — A 和 B 的坐标"""
    xa, ya, xb, yb = y
    # A 沿 y 轴匀速前进
    dxa, dya = 0.0, va
    # B 始终朝向 A
    dist = np.sqrt((xa - xb)**2 + (ya - yb)**2)
    dxb = vb * (xa - xb) / dist
    dyb = vb * (ya - yb) / dist
    return [dxa, dya, dxb, dyb]

va, vb = 1.0, 1.5   # A速, B速
sol = solve_ivp(pursuit, [0, 10], [10.0, 0.0, 0.0, 0.0],
                args=(va, vb), max_step=0.05)

plt.figure(figsize=(8, 6))
plt.plot(sol.y[0], sol.y[1], 'b-', label='A 轨迹')
plt.plot(sol.y[2], sol.y[3], 'r-', label='B 轨迹(追击)')
plt.xlabel('x'); plt.ylabel('y')
plt.title('追击曲线')
plt.legend(); plt.grid(True, alpha=0.3)
plt.axis('equal')
plt.savefig('output/pursuit.png', dpi=300)
```

## 五、偏微分方程 (PDE) 数值方法简介

### 5.1 核心方法

| 方法 | 思路 | 适用 | Python 库 |
|------|------|------|-----------|
| **有限差分 (FDM)** | 网格离散，导数→差分 | 规则区域、热传导 | 手写 / scipy |
| **有限元 (FEM)** | 区域分片，弱形式 | 不规则几何、结构力学 | FEniCS / SfePy |
| **有限体积 (FVM)** | 守恒律积分 | 流体力学 | FiPy |
| **谱方法** | 正交基展开 | 光滑周期问题 | 手写 numpy |

### 5.2 一维热传导（有限差分示例）

> ∂u/∂t = α·∂2u/∂x2, u(0,t)=0, u(L,t)=0, u(x,0)=sin(πx/L)

```python
"""
用途: 一维热传导 PDE 显式有限差分法
输入: 热扩散系数 alpha, 杆长 L, 时间 T, 网格参数
输出: 温度场 u(x,t) 的演化
"""
import numpy as np
import matplotlib.pyplot as plt

alpha = 0.01; L = 1.0; T = 2.0
nx, nt = 50, 5000
dx, dt = L/(nx-1), T/nt
x = np.linspace(0, L, nx)

# 初始条件
u = np.sin(np.pi * x / L)
u[0] = u[-1] = 0  # 边界

# 显式差分: u_new[i] = u[i] + r*(u[i+1] - 2u[i] + u[i-1])
r = alpha * dt / dx**2
assert r < 0.5, f"稳定性条件不满足 r={r:.3f}"

snapshots = [0, int(nt/4), int(nt/2), nt]
results = {}
for n in range(nt + 1):
    if n in snapshots:
        results[n] = u.copy()
    u_new = u.copy()
    for i in range(1, nx-1):
        u_new[i] = u[i] + r * (u[i+1] - 2*u[i] + u[i-1])
    u = u_new

plt.figure(figsize=(8, 4))
for n, u_snap in results.items():
    plt.plot(x, u_snap, label=f't={n*dt:.2f}')
plt.xlabel('x'); plt.ylabel('u(x,t) 温度')
plt.title('一维热传导 (显式差分)')
plt.legend(); plt.grid(True, alpha=0.3)
plt.savefig('output/heat_1d.png', dpi=300)
```

## 六、事件检测 (Events) — 数模中的实用技巧

```python
"""
用途: 使用 solve_ivp events 检测特殊时刻
场景: 落地检测、容器灌满、浓度达标
"""
from scipy.integrate import solve_ivp

def free_fall(t, y):
    return [y[1], -9.8]  # y'=v, v'=-g

def hit_ground(t, y):
    """事件函数：y=0 意味着落地"""
    return y[0]  # y坐标=0

hit_ground.terminal = True    # 触发即停止
hit_ground.direction = -1     # 仅下降时触发

sol = solve_ivp(free_fall, [0, 100], [50, 0],  # 50m 高自由落体
                events=hit_ground, max_step=0.1)
print(f"落地时间: {sol.t[-1]:.2f}s, 落地速度: {abs(sol.y[1,-1]):.2f}m/s")
# 输出: 落地时间: 3.19s, 落地速度: 31.30m/s
```

## 七、求解器选择决策树

```
拿到 ODE 问题
    ↓
是不是刚性？(时间尺度差异很大？)
    ↓ 否                  ↓ 是
method='RK45'          method='BDF' 或 'Radau'
    ↓
振荡/变化剧烈？
    ↓ 是          ↓ 否
max_step=0.1   默认即可
    ↓
需要检测特殊事件？
    ↓ 是              ↓ 否
添加 events         done
    ↓
需要精确时刻的值？
    ↓ 是                  ↓ 否
dense_output=True       只用 sol.t 处的值
```

### 边界值问题 (BVP)

```python
from scipy.integrate import solve_bvp

def ode(x, y):
    return [y[1], -abs(y[0])]  # y'' + |y| = 0

def bc(ya, yb):
    return [ya[0], yb[0] + 1]  # y(0)=0, y(1)=-1

x = np.linspace(0, 1, 20)
y_guess = np.zeros((2, 20))

sol = solve_bvp(ode, bc, x, y_guess)
```
