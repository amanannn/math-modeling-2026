1 Maxwell 方程组（时域形式）

本构关系：D = εE, B = μH, J = σE

3 简化是关键

真实 Maxwell 方程组是全耦合的、7 维度的（3 空间 + 3 场分量 + 时间）。
数模解题的核心是根据问题特征做简化：

1 FDTD（时域有限差分）— Yee 元胞法

核心思想：E 和 H 在空间和时间上交错取样，直接离散 Maxwell 旋度方程。

2 FEM（有限元法）

核心思想：区域分片，每个单元内用简单基函数逼近，组装成大型稀疏矩阵求解。

优势：处理复杂几何形状、非均匀介质
劣势：需要网格生成、矩阵求解，实现复杂

Python 可选库：FEniCS（开源）、SfePy（纯 Python）、scikit-fem

3 MoM（矩量法）

核心思想：积分方程 → 离散为矩阵方程。适合天线、散射等开域问题。

特点：只离散物体表面（不是整个空间），未知数少，但矩阵是稠密的。

1 天线覆盖问题 → 简化为几何+路径损耗

不需要跑 FDTD！用 Friis 传输方程 + 自由空间路径损耗模型即可。

3 无线充电 → 简化为耦合电感电路

用等效电路代替场求解，把电磁问题降维为电路问题。

八、国赛电磁类题目的解题策略

电磁场题目在国赛中不常见，但出现就是区分度。
核心策略：能简化就不要解全 Maxwell 方程——把场问题降维成路问题、把波动问题降维成几何问题。
真要数值求解时，一维/二维 FDTD 用 numpy 手写就够，别上来就装 FEniCS。
