# 2026 数学建模国赛备赛（CUMCM 2026）

三人队伍备战国赛 B 题的完整仓库：学习笔记、模型 Demo、历年真题、备战分析。

**队伍**：建模手 卫健康 · 编程手 谷理想 · 论文手 石智中

## 仓库结构

```
├── notes_plain/        第一阶段学习笔记（12 篇，按负责人署名）
├── models/             模型 Demo（10 个：预测/评价/优化/图论等）
├── paper/              LaTeX 论文（2024A 板凳龙、2023C 蔬菜定价）
├── pre-B/              历年国赛 B 题（2021–2025 题目 + 附件数据）
├── data/               数据文件（xlsx 等不入库）
├── utils/              公共工具代码
├── templates/          模板文件
├── output/             运行输出
├── requirements.txt    依赖清单
└── 2026年B题备战分析总结.md   赛前决策与分析（推荐实战 2023 多波束测线）
```

## 内容索引

- **学习笔记**（notes_plain/）：微分方程、决策模型、图建模、优化方法、智能优化算法等 12 篇
- **模型 Demo**（models/）：每篇笔记配一个可运行示例，含可视化图
- **真题资料**（pre-B/）：2021–2025 年国赛 B 题 PDF 与附件
- **备战分析**：历年 B 题规律、方法库匹配度、赛前实战决策与 8 天执行框架

## 快速开始

```bash
conda create -n mathmodel python=3.10 -y
conda activate mathmodel
pip install -r requirements.txt
```

## 备战路线

- 8.12–9.6 暑期集训（3 轮实训：预测评价 → 优化仿真 → 全真模拟）
- 9.1–9.9 校内报名
- 9.10 18:00 – 9.13 20:00 国赛（72 小时）
